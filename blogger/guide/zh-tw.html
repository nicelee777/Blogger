1. 開始使用

不必從頭讀完所有說明。只要熟悉以下流程，就能立即開始使用。

5 分鐘開始使用 ShiftMate
  1. 底部的班次分頁中，點選上方的 輸入來輸入第一個班次。
  2. 更多 → 鬧鐘設定中開啟所用班次的上班鬧鐘，並確認時間。
  3. 將 ShiftMate 新增至手機 主畫面小工具。
  4. 如有需要，可透過 更多 → 分享班次 → 傳送連結向同事傳送邀請連結。
推薦
一開始只要設定 輸入班次 → 上班鬧鐘 → 主畫面小工具就足夠了。

2. 班表

在底部的 班次 分頁中輸入並確認 D、E、N、OFF 等輪班班次。

輸入班次

班次 → 輸入中編輯班表。

  1. 開啟底部的 班次 分頁。
  2. 點選畫面上方的 輸入。
  3. 在日曆中選擇要輸入的日期。
  4. 點選下方所需的班次按鈕，例如 D、E、N、OFF。
  5. 輸入完成後，點選右上角的 儲存。
快速連續輸入一個月的班表

ShiftMate 的班次輸入畫面不是一次選擇多個日期， 而是在某個日期輸入班次後，自動將選取位置移至下一個日期的方式。 一邊查看班表，一邊依序點選 D → E → N → OFF，即可快速輸入整個月的班次。

  1. 班次 → 輸入。
  2. 選擇開始輸入的日期。
  3. 點選該日期的班次按鈕。
  4. 選取標記移至下一個日期後，繼續點選下一個班次。
  5. 全部輸入後，點選右上角的 儲存。
Tip
如果需要修改中間的日期，可以在日曆中重新選擇該日期，接著輸入。
修改・刪除班次

班次 → 輸入中選擇要修改的日期，點選其他班次，或選擇 刪除後，再點選 儲存。

設定我使用的班次

更多 → 班次設定中管理班次名稱、顏色、班次時間及要使用的班次。

也可以在所有設定中，透過 更多 → 右上角的所有設定 → 班次、考勤與請假 → 班次設定進入。
查看班次分析

更多 → 班次分析中查看已輸入班次的期間統計。可用於查看各班次的次數與模式。

3. 行程

ShiftMate 會將裝置行事曆中的個人行程與班次一起顯示，並連結行程新增與修改功能。

新增個人行程

在底部的 班次 分頁中選擇所需日期後，可從按鈕新增行程。在 ShiftMate 的行程編輯畫面中填寫內容後，會儲存至所選的裝置行事曆。 +

若要將個人行程與班表一起使用，需要裝置的 行事曆存取權限。
設定重複行程與行程鬧鐘

在行程編輯畫面中，可以設定每天、每週、每月、每年等 重複設定以及行程 鬧鐘。

變更班次・行程顯示方式

更多 → 右上角的所有設定 → 畫面設定中調整班次與行程的顯示方式及大小。

管理同事

5. 上班鬧鐘

配合不同班次的上班時間，為各班次設定不同的鬧鐘。

開啟上班鬧鐘
  1. 開啟底部的 更多開啟。
  2. 鬧鐘設定選擇。
  3. 要使用鬧鐘的班次右側 開關將其開啟。
  4. 出現權限說明時，請允許所需的鬧鐘與通知權限。
變更各班次的鬧鐘時間

更多 → 鬧鐘設定在其中點選所需的班次卡片，即可變更該班次的鬧鐘時間。變更內容不需按下另外的儲存按鈕，會直接套用至設定。

設定鬧鐘聲音、震動與鬧鐘畫面

更多 → 右上角所有設定 → 鬧鐘可在其中查看上班鬧鐘、聲音與震動，以及鬧鐘畫面的相關設定。

鬧鐘沒有響嗎？查看上班鬧鐘問題的解決方法 →

6. 主畫面小工具

無需開啟應用程式，即可在手機主畫面查看班次。

在 iPhone 新增 ShiftMate 小工具
  1. 長按 iPhone 主畫面，進入編輯模式。
  2. 新增小工具搜尋 ShiftMate。
  3. 選擇所需的小工具大小與樣式。
  4. 將其放置在主畫面上。
在 Android 新增 ShiftMate 小工具
  1. 長按主畫面，然後 小工具 開啟選單。
  2. 尋找 ShiftMate。
  3. 將所需的小工具新增至主畫面。
根據 Android 製造商與版本不同，新增小工具畫面的名稱與位置可能略有差異。
設定小工具顯示內容

更多 → 小工具設定可在其中設定要顯示於 ShiftMate 小工具中的班次與相關選項。實際將小工具新增至主畫面的操作，請在 iPhone/Android 的主畫面上進行。

7. 備忘錄

底部 備忘錄 可在分頁中管理一般備忘錄與核取清單備忘錄。

撰寫備忘錄
  1. 底部 備忘錄 開啟分頁。
  2. + 按下按鈕以開啟備忘錄。
  3. 輸入標題與內容。
  4. 底部 儲存按下。
使用核取清單備忘錄

如果想逐項確認待辦事項，可以將備忘錄類型 核取清單備忘錄改為此類型，並新增核取項目。

尋找與排序備忘錄

利用備忘錄清單的篩選與排序功能，可以依一般備忘錄、核取清單備忘錄、完成狀態、日期等條件快速尋找所需的備忘錄。

8. 考勤與分析

年假、病假、教育訓練、出差、遲到、早退等需要與班表分開管理的記錄，請以考勤管理。

新增考勤記錄

在班次日曆中選擇日期，開啟日期詳細畫面後 + 在按鈕中 考勤選擇即可新增記錄。

若要新增或修改考勤類型本身，請使用 更多 → 右上角所有設定 → 班次、考勤與請假 → 考勤設定。
查看班次分析與考勤概況

更多 → 班次分析可查看班次模式， 更多 → 考勤概況可按期間查看考勤記錄。在考勤概況中， 本月・上月・最近 3 個月・今年・去年 或 自行選擇設定查詢期間。

9. 帳戶、資料與設定

底部 更多與右上角的 所有設定可管理主要設定與支援選單。

瀏覽所有設定

更多 → 右上角所有設定可管理以下區域。

  • 班次、考勤與請假 — 班次類型、考勤、班次畫面
  • 鬧鐘 — 上班鬧鐘、聲音、震動
  • 行事曆 — 地區、每週開始日、要顯示的行事曆
  • 畫面設定 — 班次與行程的顯示方式及大小
  • 主題 — 畫面模式、色彩、字型
  • 主畫面小工具 — 每月、每日／每週小工具設定
登入與帳戶

登入可用於使用班次資料自動備份與分享功能。更換手機前，請先確認目前使用的帳戶資訊。

確認資料備份與還原

登入後即可使用支援資料的備份、同步及分享班次功能。備份與還原的對象可能依應用程式版本及資料類型而異，因此在更換裝置或重新安裝應用程式前，請確認目前登入的帳戶。請在新裝置上使用相同帳戶登入。

傳送幫助、詢問與意見

所有設定 → 幫助與支援可在其中使用 FAQ、聯絡我們、意見與改進建議、評價 ShiftMate。

10. 發生問題時

正常的使用方法請參閱本指南；若遇到錯誤或非預期的行為，請前往 FAQ查看。

  • 上班鬧鐘沒有響。
  • 主畫面小工具沒有更新。
  • 同事的班次沒有顯示最新狀態。
  • 分享連結無法開啟。
  • 登入、驗證或資料還原發生問題。
  • 行程或假日顯示異常。
