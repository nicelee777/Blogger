1. 開始使用

不必從頭讀完整份說明。只要熟悉以下流程，就能立即開始使用。

5 分鐘開始使用 ShiftMate
  1. 底部的班次分頁中，點選上方的 輸入以輸入第一個班次。
  2. 更多 → 鬧鐘設定開啟所使用班次的上班鬧鐘，並確認時間。
  3. 在手機主畫面新增 ShiftMate 主畫面小工具。
  4. 如有需要，透過 更多 → 分享班次 → 傳送連結將邀請連結傳給同事。
推薦
一開始只要設定 輸入班次 → 上班鬧鐘 → 主畫面小工具就足夠了。

2. 班表

底部的 班次 分頁中輸入並確認 D、E、N、OFF 等輪班班次。

輸入班次

班次 → 輸入以編輯班表。

  1. 開啟底部的 班次 分頁。
  2. 點選畫面上方的 輸入。
  3. 在日曆中選擇要輸入的日期。
  4. 點選下方所需的班次按鈕，例如 D、E、N、OFF。
  5. 輸入完成後，點選右上角的 儲存。
快速連續輸入一個月的班表

ShiftMate 的輸入班次畫面不是一次選取多個日期，而是 輸入某一天的班次後，選取位置會自動移至下一天。查看班表後，依序點選 D → E → N → OFF，即可快速輸入整個月的班次。

  1. 班次 → 輸入。
  2. 選擇開始輸入的日期。
  3. 點選該日期的班次按鈕。
  4. 選取標記移至下一天後，繼續點選下一個班次。
  5. 全部輸入後，點選右上角的 儲存。
Tip
若要修改中間的日期，可在日曆中重新選擇該日期並繼續輸入。
修改・刪除班次

班次 → 輸入中選擇要修改的日期，點選其他班次，或選擇 刪除後再點選 儲存。

設定我使用的班次

更多 → 班次設定以管理班次名稱、顏色、班次時間及要使用的班次。

在所有設定中，也可以透過 更多 → 右上角的所有設定 → 班次、考勤與請假 → 班次設定進入。
查看班次分析

更多 → 班次分析可依期間查看已輸入的班次。適合用來查看各班次類型的次數與模式。

3. 行程

ShiftMate 會將裝置日曆中的個人行程與班次一同顯示，並連結行程新增與修改功能。

新增個人行程

在底部的 班次 分頁中選擇所需日期後，點選 + 按鈕即可新增行程。在 ShiftMate 的行程編輯畫面中輸入內容後，會儲存至所選的裝置日曆。

若要將個人行程與班表搭配使用，需要裝置的 日曆存取權限。
設定重複行程與行程鬧鐘

在行程編輯畫面中，可以設定每天、每週、每月、每年等 重複設定以及行程 鬧鐘。

變更班次・行程的顯示方式

更多 → 右上角的所有設定 → 畫面設定可調整班次與行程的顯示方式及大小。

4. 同事・分享班次

透過邀請連結與同事連結，並在底部的 同事 分頁中一起查看分享的班次。

傳送分享班次連結給同事
  1. 開啟底部的 更多。
  2. 分享班次。
  3. 傳送連結。
  4. 使用 KakaoTalk、簡訊等所需的應用程式傳送邀請連結。
  5. 對方完成連結後，在底部的 同事 分頁中查看。
查看同事班次

已連結同事的班次可在底部的 同事 分頁中查看。系統會先顯示已儲存的內容，再確認最新資料； 進入同事畫面或切換月份時，會再次確認最新分享的班次。

最新班次的套用方式可能會因應用程式版本與功能設定而異。
管理同事

在底部的 同事 畫面中，可使用同事管理功能新增同事，或整理顯示順序、篩選條件與連結狀態。

5. 上班鬧鐘

依照各班次不同的上班時間，設定各班次的鬧鐘。

開啟上班鬧鐘
  1. 開啟底部的 更多開啟。
  2. 鬧鐘設定選擇。
  3. 要使用鬧鐘的班次右側 開關開啟。
  4. 出現權限說明時，請允許必要的鬧鐘與通知權限。
變更各班次的鬧鐘時間

更多 → 鬧鐘設定在其中點選想要的班次卡片，即可變更該班次的鬧鐘時間。變更內容會直接套用至設定，無須另外按下儲存按鈕。

設定鬧鐘聲音、震動與鬧鐘畫面

更多 → 右上角所有設定 → 鬧鐘可在其中查看上班鬧鐘、聲音與震動，以及鬧鐘畫面的相關設定。

鬧鐘沒有響嗎？查看上班鬧鐘疑難排解 →

6. 主畫面小工具

無須開啟應用程式，即可在手機主畫面查看班次。

在 iPhone 新增 ShiftMate 小工具
  1. 長按 iPhone 主畫面，進入編輯模式。
  2. 新增小工具搜尋 ShiftMate。
  3. 選擇想要的小工具大小與樣式。
  4. 放置在主畫面上。
在 Android 新增 ShiftMate 小工具
  1. 長按主畫面，然後 小工具 開啟選單。
  2. 尋找 ShiftMate。
  3. 將想要的小工具新增至主畫面。
依 Android 製造商與版本而定，新增小工具畫面的名稱與位置可能略有不同。
設定小工具顯示內容

更多 → 小工具設定可在其中設定要顯示於 ShiftMate 小工具的班次與相關選項。實際將小工具新增至主畫面的操作，請在 iPhone／Android 的主畫面上進行。

7. 備忘錄

底部 備忘錄 可在分頁管理一般備忘錄與核取清單備忘錄。

撰寫備忘錄
  1. 底部 備忘錄 開啟分頁。
  2. + 按下按鈕開啟備忘錄。
  3. 輸入標題與內容。
  4. 底部 儲存按下。
使用核取清單備忘錄

如果想逐項確認待辦事項，可以將備忘錄類型 核取清單備忘錄變更為，並新增核取項目。

尋找與排序備忘錄

利用備忘錄清單的篩選與排序功能，可依一般備忘錄／核取清單備忘錄、完成狀態、日期等條件快速找到所需備忘錄。

8. 考勤與分析

年假、病假、教育訓練、出差、遲到、早退等需要與班表分開管理的記錄，皆以考勤管理。

新增考勤記錄

在班次月曆中選擇日期，開啟日期詳細畫面後 + 在按鈕中 考勤選擇，即可新增記錄。

若要新增或修改考勤類型本身，請使用 更多 → 右上角所有設定 → 班次、考勤與請假 → 考勤設定。
查看班次分析與考勤概況

更多 → 班次分析可查看班次模式， 更多 → 考勤概況可依期間查看考勤記錄。在考勤概況中， 本月・上月・最近 3 個月・今年・去年 或 自行選擇查詢期間。

9. 帳戶、資料與設定

底部 更多與右上角的 所有設定可管理主要設定與支援選單。

瀏覽所有設定

更多 → 右上角所有設定可管理以下項目。

  • 班次、考勤與請假 — 班次類型、考勤、班次畫面
  • 鬧鐘 — 上班鬧鐘、聲音、震動
  • 行事曆 — 地區、每週開始日、要顯示的行事曆
  • 螢幕設定 — 班次與行程的顯示方式及大小
  • 主題 — 螢幕模式、色彩、字型
  • 主畫面小工具 — 每月、每日／每週小工具設定
登入與帳戶

登入可用於使用班次資料自動備份與分享功能。更換手機前，請先確認目前使用的帳戶資訊。

確認資料備份與還原

登入後即可使用支援資料的備份與同步，以及分享班次功能。備份與還原的對象可能依應用程式版本及資料類型而異，因此在更換裝置或重新安裝應用程式前，請確認目前登入的帳戶。請在新裝置上使用相同帳戶登入。

傳送幫助、問題與意見

所有設定 → 幫助與支援可在其中使用 FAQ、聯絡我們、意見與改進建議、評價 ShiftMate。

10. 遇到問題時

正常使用方式請參閱本指南，錯誤或未預期的行為請至 FAQ查看。

  • 上班鬧鐘沒有響。
  • 主畫面小工具沒有更新。
  • 看不到同事最新的班次。
  • 分享連結無法開啟。
  • 登入、驗證或資料還原發生問題。
  • 行程或假日顯示異常。
