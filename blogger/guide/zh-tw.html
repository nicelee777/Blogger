1. 開始使用

不需要從頭到尾讀完整份說明。只要熟悉以下流程，就能立即開始使用。

5 分鐘開始使用 ShiftMate
  1. 在下方的班次分頁點選上方的輸入，輸入第一個班次。
  2. 前往顯示更多 → 鬧鐘設定，開啟所使用班次的上班鬧鐘並確認時間。
  3. 在手機主畫面新增 ShiftMate 主畫面小工具。
  4. 如有需要，前往顯示更多 → 分享班次 → 傳送連結，將邀請連結傳給同事。
建議
一開始只設定輸入班次 → 上班鬧鐘 → 主畫面小工具就已經足夠。

2. 班表

在下方班次分頁輸入並查看自己的輪班，例如 D、E、N、Off。

輸入班次

在班次 → 輸入編輯班表。

  1. 開啟下方的班次分頁。
  2. 點選畫面上方的輸入。
  3. 在日曆中選擇要輸入的日期。
  4. 點選下方 D、E、N、Off 等所需的班次按鈕。
  5. 輸入完成後，點選右上方的儲存。
快速連續輸入一個月的班表

ShiftMate 的班次輸入畫面不是一次選擇多個日期， 而是在某一天輸入班次後，選取位置會自動移動到下一天。 對照班表依序點選 D → E → N → Off，即可快速輸入整個月的班次。

  1. 開啟班次 → 輸入。
  2. 選擇開始輸入的日期。
  3. 點選該日期的班次按鈕。
  4. 選取標示移動到下一天後，繼續點選下一個班次。
  5. 全部輸入後，點選右上方的儲存。
Tip
若需要修改中間的日期，可在日曆中重新選擇該日期，直接繼續輸入。
修改・刪除班次

在班次 → 輸入中選擇要修改的日期，點選其他班次或選擇刪除，然後儲存。

設定自己使用的班次

在顯示更多 → 班次設定中管理班次名稱、顏色、班次時間與要使用的班次。

也可以在完整設定中前往顯示更多 → 右上方完整設定 → 班次與勤務 → 班次設定。
查看班次分析

在顯示更多 → 班次分析中依期間查看已輸入的班次。可用於查看各班次種類的次數與模式。

3. 行程

ShiftMate 會將裝置日曆中的個人行程與班次一同顯示，並連結新增與修改行程的功能。

新增個人行程

在下方班次分頁選擇所需日期後，使用+按鈕即可新增行程。視裝置與作業系統而定，可能會開啟系統日曆畫面。

若要將個人行程與班表一同查看，需要裝置的日曆存取權限。
設定重複行程與行程通知

在行程編輯畫面中，可以設定每天・每週・每月・每年等重複設定與行程通知。

變更班次・行程的顯示方式

在顯示更多 → 右上方完整設定 → 畫面設定中調整班次與行程的顯示方式和大小。

4. 同事・分享班次

透過邀請連結與同事連線，並在下方同事分頁一同查看分享的班次。

傳送分享班次連結給同事
  1. 開啟下方的顯示更多。
  2. 選擇分享班次。
  3. 選擇傳送連結。
  4. 使用 KakaoTalk、簡訊等所需的應用程式傳送邀請連結。
  5. 對方完成連線後，在下方同事分頁查看。
查看同事班次

在下方同事分頁查看已連線同事的班次。會先顯示已儲存的內容，再確認最新資料；進入同事畫面或切換月份時，會確認伺服器上最新分享的班次。

同事變更班次的瞬間自動傳送到畫面的即時接收功能，是另外的功能。
管理同事

在下方同事畫面使用同事管理功能，新增同事或整理顯示順序、篩選條件與連線狀態。

5. 上班鬧鐘

配合各班次不同的上班時間，設定各班次的鬧鐘。

開啟上班鬧鐘
  1. 開啟下方的顯示更多。
  2. 選擇鬧鐘設定。
  3. 開啟要使用鬧鐘之班次右側的開關。
  4. 出現權限提示時，允許必要的鬧鐘與通知權限。
變更各班次的鬧鐘時間

在顯示更多 → 鬧鐘設定中點選所需的班次卡片，即可變更該班次的鬧鐘時間。變更內容不需另外按儲存按鈕，會直接套用到設定。

設定鬧鐘聲音・震動・鬧鐘畫面

在顯示更多 → 右上方完整設定 → 鬧鐘中確認上班鬧鐘、聲音與震動、鬧鐘畫面相關設定。

鬧鐘沒有響嗎？查看上班鬧鐘疑難排解 →

6. 主畫面小工具

不開啟應用程式，也能在手機主畫面查看班次。

在 iPhone 新增 ShiftMate 小工具
  1. 長按 iPhone 主畫面，進入編輯狀態。
  2. 在新增小工具中搜尋 ShiftMate。
  3. 選擇所需的小工具大小與形式。
  4. 放置到主畫面。
在 Android 新增 ShiftMate 小工具
  1. 長按主畫面，開啟小工具選單。
  2. 尋找 ShiftMate。
  3. 將所需的小工具新增到主畫面。
視 Android 製造商與版本而定，新增小工具畫面的名稱和位置可能略有不同。
設定小工具顯示內容

在顯示更多 → 小工具設定中設定要顯示在 ShiftMate 小工具上的班次與相關選項。實際將小工具新增至主畫面的操作，請在 iPhone/Android 的主畫面中進行。

7. 備忘錄

在下方備忘錄分頁管理一般備忘錄與勾選備忘錄。

撰寫備忘錄
  1. 開啟下方的備忘錄分頁。
  2. 點選+按鈕開啟備忘錄。
  3. 撰寫標題與內容。
  4. 點選下方的儲存。
使用勾選備忘錄

如果想逐項確認待辦事項，可以將備忘錄種類切換為勾選備忘錄，新增勾選項目。

尋找・排序備忘錄

使用備忘錄清單的篩選與排序功能，依一般備忘錄・勾選備忘錄、完成狀態、日期等條件快速尋找所需備忘錄。

8. 勤務・分析

將年假、病假、教育、出差、遲到、早退等需與班表分開管理的紀錄，以勤務進行管理。

新增勤務紀錄

在班次日曆中選擇日期，開啟日期詳細畫面後，點選+按鈕中的勤務即可新增紀錄。

若要新增或修改勤務種類本身，請使用顯示更多 → 右上方完整設定 → 班次與勤務 → 勤務設定。
查看班次分析・勤務狀況

在顯示更多 → 班次分析查看班次模式，在顯示更多 → 勤務狀況依期間查看勤務紀錄。勤務狀況可選擇本月・上月・最近 3 個月・今年等查詢期間。

9. 帳戶・資料・設定

在下方顯示更多與右上方完整設定管理主要設定與支援選單。

瀏覽完整設定

在顯示更多 → 右上方完整設定中可管理以下區域。

  • 班次與勤務 — 班次種類、勤務、班次畫面
  • 鬧鐘 — 上班鬧鐘、聲音、震動
  • 日曆 — 地區、每週開始日、要顯示的日曆
  • 畫面設定 — 班次・行程的顯示方式與大小
  • 主題 — 畫面模式、顏色、字型
  • 主畫面小工具 — 每月・每日/每週小工具設定
登入與帳戶

登入可用於使用班次資料自動備份與分享功能。更換手機前，請先確認目前使用的帳戶資訊。

確認資料備份・還原

登入後，班次・備忘錄・勤務等支援的資料會依帳戶保存。重新安裝或更換裝置前，請確認網路連線狀態與登入帳戶，並在新裝置上使用相同帳戶登入。

傳送說明・詢問・意見

在完整設定 → 說明與支援中可使用常見問題、聯絡我們、意見與改進建議、評價 ShiftMate。

10. 發生問題時

正常的使用方式請在本指南中確認，錯誤或未預期的行為請查看常見問題。

  • 上班鬧鐘沒有響。
  • 主畫面小工具沒有更新。
  • 同事的班次沒有顯示為最新狀態。
  • 分享連結無法開啟。
  • 登入・驗證或資料還原發生問題。
  • 行程或假日顯示異常。
