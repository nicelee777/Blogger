1. 시작하기

설명서를 처음부터 모두 읽을 필요는 없습니다. 아래 흐름만 익히면 바로 사용할 수 있습니다.

5분 만에 ShiftMate 시작하기
  1. 하단의 근무 탭에서 상단 입력을 눌러 첫 근무를 입력합니다.
  2. 더보기 → 알람설정에서 사용하는 근무의 출근 알람을 켜고 시간을 확인합니다.
  3. 휴대폰 홈 화면에 ShiftMate 홈 위젯을 추가합니다.
  4. 필요하면 더보기 → 근무공유 → 링크 전송으로 동료에게 초대 링크를 보냅니다.
추천
처음에는 근무 입력 → 출근 알람 → 홈 위젯만 설정해도 충분합니다.

2. 근무표

하단 근무 탭에서 D, E, N, Off 등 내 교대근무를 입력하고 확인합니다.

근무 입력하기

근무 → 입력에서 근무표를 편집합니다.

  1. 하단 근무 탭을 엽니다.
  2. 화면 상단의 입력을 누릅니다.
  3. 달력에서 입력할 날짜를 선택합니다.
  4. 아래의 D, E, N, Off 등 원하는 근무 버튼을 누릅니다.
  5. 입력이 끝나면 오른쪽 위 저장을 누릅니다.
한 달 근무표 빠르게 연속 입력하기

ShiftMate 근무 입력 화면은 여러 날짜를 한꺼번에 선택하는 방식이 아니라, 한 날짜에 근무를 입력하면 선택 위치가 다음 날짜로 자동 이동하는 방식입니다. 근무표를 보면서 D → E → N → Off처럼 순서대로 눌러 빠르게 한 달 근무를 입력할 수 있습니다.

  1. 근무 → 입력을 엽니다.
  2. 입력을 시작할 날짜를 선택합니다.
  3. 그 날짜의 근무 버튼을 누릅니다.
  4. 선택 표시가 다음 날짜로 이동하면 다음 근무를 계속 누릅니다.
  5. 모두 입력한 뒤 오른쪽 위 저장을 누릅니다.
Tip
중간 날짜를 수정해야 하면 달력에서 해당 날짜를 다시 선택해 바로 이어서 입력할 수 있습니다.
근무 수정·삭제하기

근무 → 입력에서 수정할 날짜를 선택해 다른 근무를 누르거나 삭제를 선택한 뒤 저장합니다.

내가 사용하는 근무 설정하기

더보기 → 근무설정에서 근무명, 색상, 근무시간과 사용할 근무를 관리합니다.

전체 설정에서는 더보기 → 오른쪽 위 전체설정 → 근무 및 복무 → 근무설정으로도 들어갈 수 있습니다.
근무분석 확인하기

더보기 → 근무분석에서 입력한 근무를 기간별로 확인할 수 있습니다. 근무 종류별 횟수와 패턴을 살펴볼 때 활용하세요.

3. 일정

ShiftMate는 기기 캘린더의 개인 일정을 근무와 함께 보여주고 일정 추가·수정 기능을 연결합니다.

개인 일정 추가하기

하단 근무 탭에서 원하는 날짜를 선택한 뒤 + 버튼에서 일정을 추가할 수 있습니다. ShiftMate의 일정 편집 화면에서 내용을 작성하면 선택한 기기 캘린더에 저장됩니다.

개인 일정을 근무표와 함께 사용하려면 기기의 캘린더 접근 권한이 필요합니다.
반복 일정과 일정 알림 설정하기

일정 편집 화면에서 매일·매주·매월·매년 등의 반복 설정과 일정 알림을 설정할 수 있습니다.

근무·일정 표시 방법 바꾸기

더보기 → 오른쪽 위 전체설정 → 화면 설정에서 근무와 일정의 표시 방식과 크기를 조정할 수 있습니다.

4. 동료·근무 공유

초대 링크로 동료와 연결하고 하단 동료 탭에서 공유된 근무를 함께 확인합니다.

동료에게 근무 공유 링크 보내기
  1. 하단 더보기를 엽니다.
  2. 근무공유를 선택합니다.
  3. 링크 전송을 선택합니다.
  4. 카카오톡, 문자 등 원하는 앱으로 초대 링크를 보냅니다.
  5. 상대방이 연결을 완료하면 하단 동료 탭에서 확인합니다.
동료 근무 확인하기

연결된 동료의 근무는 하단 동료 탭에서 확인합니다. 저장된 내용을 먼저 보여준 뒤 최신 데이터를 확인하며, 동료 화면에 들어가거나 월을 변경하면 최신 공유 근무를 다시 확인합니다.

최신 근무 반영 방식은 앱 버전과 기능 설정에 따라 달라질 수 있습니다.
동료 관리하기

하단 동료 화면에서 동료 관리 기능을 이용해 동료를 추가하거나 표시 순서·필터·연결 상태를 정리할 수 있습니다.

5. 출근 알람

근무 종류마다 다른 출근 시간에 맞춰 근무별 알람을 설정합니다.

출근 알람 켜기
  1. 하단 더보기를 엽니다.
  2. 알람설정을 선택합니다.
  3. 알람을 사용할 근무의 오른쪽 스위치를 켭니다.
  4. 권한 안내가 나타나면 필요한 알람·알림 권한을 허용합니다.
근무별 알람 시간 바꾸기

더보기 → 알람설정에서 원하는 근무 카드를 누르면 해당 근무의 알람 시간을 변경할 수 있습니다. 변경 내용은 별도의 저장 버튼 없이 설정에 반영됩니다.

알람음·진동·알람 화면 설정하기

더보기 → 오른쪽 위 전체설정 → 알람에서 출근 알람, 소리 및 진동, 알람 화면 관련 설정을 확인할 수 있습니다.

6. 홈 위젯

휴대폰 홈 화면에서 앱을 열지 않고 근무를 확인할 수 있습니다.

iPhone에 ShiftMate 위젯 추가하기
  1. iPhone 홈 화면을 길게 누르고 편집 상태로 들어갑니다.
  2. 위젯 추가에서 ShiftMate를 검색합니다.
  3. 원하는 위젯 크기와 형태를 선택합니다.
  4. 홈 화면에 배치합니다.
Android에 ShiftMate 위젯 추가하기
  1. 홈 화면을 길게 누르고 위젯 메뉴를 엽니다.
  2. ShiftMate를 찾습니다.
  3. 원하는 위젯을 홈 화면으로 추가합니다.
Android 제조사와 버전에 따라 위젯 추가 화면의 명칭과 위치가 조금 다를 수 있습니다.
위젯 표시 내용 설정하기

더보기 → 위젯설정에서 ShiftMate 위젯에 표시할 근무와 관련 옵션을 설정할 수 있습니다. 홈 화면에 위젯을 실제로 추가하는 작업은 iPhone/Android의 홈 화면에서 진행합니다.

7. 메모

하단 메모 탭에서 일반 메모와 체크메모를 관리합니다.

메모 작성하기
  1. 하단 메모 탭을 엽니다.
  2. + 버튼을 눌러 메모를 엽니다.
  3. 제목과 내용을 작성합니다.
  4. 하단 저장을 누릅니다.
체크메모 사용하기

해야 할 일을 항목별로 확인하고 싶다면 메모의 종류를 체크메모로 바꿔 체크 항목을 추가할 수 있습니다.

메모 찾기·정렬하기

메모 목록의 필터와 정렬 기능을 이용해 일반 메모·체크메모, 완료 여부, 날짜 등의 조건으로 필요한 메모를 빠르게 찾을 수 있습니다.

8. 복무·분석

연차, 병가, 교육, 출장, 지각, 조퇴 등 근무표와 별도로 관리할 기록을 복무로 관리합니다.

복무 기록 추가하기

근무 달력에서 날짜를 선택해 날짜 상세 화면을 연 뒤 + 버튼에서 복무를 선택해 기록을 추가할 수 있습니다.

복무 종류 자체를 추가하거나 수정하려면 더보기 → 오른쪽 위 전체설정 → 근무 및 복무 → 복무 설정을 이용하세요.
근무분석·복무현황 확인하기

더보기 → 근무분석에서 근무 패턴을, 더보기 → 복무현황에서 복무 기록을 기간별로 확인할 수 있습니다. 복무현황에서는 이번 달·지난 달·최근 3개월·올해·작년 또는 직접 선택으로 조회 기간을 설정할 수 있습니다.

9. 계정·데이터·설정

하단 더보기와 오른쪽 위 전체설정에서 주요 설정과 지원 메뉴를 관리합니다.

전체 설정 둘러보기

더보기 → 오른쪽 위 전체설정에서 다음 영역을 관리할 수 있습니다.

  • 근무 및 복무 — 근무 종류, 복무, 근무 화면
  • 알람 — 출근 알람, 소리, 진동
  • 캘린더 — 지역, 주 시작 요일, 표시할 캘린더
  • 화면 설정 — 근무·일정 표시 방식과 크기
  • 테마 — 화면 모드, 색상, 글꼴
  • 홈 위젯 — 월간·일간/주간 위젯 설정
로그인과 계정

로그인은 근무 데이터 자동 백업과 공유 기능을 이용하는 데 사용됩니다. 휴대폰을 바꾸기 전에는 현재 사용 중인 계정 정보를 확인해두세요.

데이터 백업·복원 확인하기

로그인하면 지원되는 데이터의 백업·동기화와 근무 공유 기능을 이용할 수 있습니다. 백업·복원 대상은 앱 버전과 데이터 종류에 따라 다를 수 있으므로, 기기를 변경하거나 앱을 재설치하기 전에는 현재 로그인 계정을 확인하세요. 새 기기에서도 같은 계정으로 로그인하세요.

도움말·문의·의견 보내기

전체설정 → 도움말 및 지원에서 자주 묻는 질문, 문의하기, 의견 및 개선 제안, ShiftMate 평가하기를 이용할 수 있습니다.

10. 문제가 있을 때

정상적인 사용 방법은 이 가이드에서 확인하고, 오류나 예상하지 못한 동작은 자주 묻는 질문에서 확인해주세요.

  • 출근 알람이 울리지 않아요.
  • 홈 위젯이 갱신되지 않아요.
  • 동료의 근무가 최신 상태로 보이지 않아요.
  • 공유 링크가 열리지 않아요.
  • 로그인·인증 또는 데이터 복원에 문제가 있어요.
  • 일정이나 공휴일 표시가 이상해요.
