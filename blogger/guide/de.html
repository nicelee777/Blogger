1. Starten

Sie müssen das Handbuch nicht von Anfang bis Ende lesen. Wenn Sie nur den folgenden Ablauf kennen, können Sie sofort loslegen.

In 5 Minuten mit ShiftMate starten
  1. Schicht-Tab unten oben Eintragen tippen Sie, um Ihre erste Schicht einzutragen.
  2. Mehr → Alarmeinstellungen aktivieren Sie den Schichtalarm für die verwendete Schicht und prüfen Sie die Uhrzeit.
  3. Fügen Sie ShiftMate zum Startbildschirm-Widget auf dem Startbildschirm Ihres Smartphones hinzu.
  4. Bei Bedarf Mehr → Schicht teilen → Link senden senden Sie Ihren Kollegen einen Einladungslink.
Empfehlung
Am Anfang reicht es, Schicht eintragen → Schichtalarm → Startbildschirm-Widget einzurichten.

2. Dienstplan

unten im Schicht Tab können Sie Ihre Schichten wie D, E, N und OFF eintragen und überprüfen.

Schicht eintragen

Schicht → Eintragen bearbeiten Sie den Dienstplan.

  1. Öffnen Sie unten den Schicht Tab.
  2. Tippen Sie oben auf dem Bildschirm auf Eintragen.
  3. Wählen Sie im Kalender das Datum aus, für das Sie eine Schicht eintragen möchten.
  4. Tippen Sie auf die gewünschte Schicht, etwa D, E, N oder OFF.
  5. Wenn Sie fertig sind, tippen Sie oben rechts auf Speichern.
Dienstplan für einen Monat schnell fortlaufend eintragen

Im Eingabebildschirm von ShiftMate werden nicht mehrere Tage auf einmal ausgewählt, sondern nach dem Eintragen einer Schicht für einen Tag wird die Auswahl automatisch auf den nächsten Tag verschoben So können Sie den Dienstplan für einen Monat schnell eintragen, indem Sie beim Blick auf den Dienstplan der Reihe nach D → E → N → OFF antippen.

  1. Schicht → Eintragen Öffnen Sie
  2. Wählen Sie das Datum aus, an dem Sie mit der Eingabe beginnen möchten.
  3. Tippen Sie auf die Schicht für diesen Tag.
  4. Wenn die Auswahl zum nächsten Datum wechselt, tippen Sie mit der nächsten Schicht fort.
  5. Nachdem Sie alles eingetragen haben, tippen Sie oben rechts auf Speichern.
Tip
Wenn Sie ein Datum in der Mitte ändern müssen, wählen Sie es im Kalender erneut aus und setzen Sie die Eingabe direkt fort.
Schichten bearbeiten und löschen

Schicht → Eintragen Wählen Sie das zu bearbeitende Datum aus und tippen Sie auf eine andere Schicht oder wählen Sie Löschen und anschließend Speichern.

Ihre Schichten einrichten

Mehr → Schichteinstellungen verwalten Sie Schichtnamen, Farben, Schichtzeiten und die verwendeten Schichten.

Über Alle Einstellungen Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Schichteinstellungen können Sie ebenfalls dorthin gelangen.
Schichtanalyse anzeigen

Mehr → Schichtanalyse können Sie Ihre eingetragenen Schichten nach Zeitraum überprüfen. Nutzen Sie diese Funktion, um die Anzahl und Muster der einzelnen Schichtarten zu betrachten.

3. Termine

ShiftMate zeigt persönliche Termine aus dem Gerätekalender zusammen mit Ihren Schichten an und verknüpft Funktionen zum Hinzufügen und Bearbeiten von Terminen.

Persönlichen Termin hinzufügen

Wählen Sie unten im Schicht Tab das gewünschte Datum aus und + über die Schaltfläche können Sie einen Termin hinzufügen. Wenn Sie den Inhalt im Terminbearbeitungsbildschirm von ShiftMate eingeben, wird er im ausgewählten Gerätekalender gespeichert.

Um persönliche Termine zusammen mit dem Dienstplan zu verwenden, benötigen Sie die Kalenderzugriffsberechtigung des Geräts.
Wiederkehrende Termine und Terminerinnerungen einrichten

Im Terminbearbeitungsbildschirm können Sie für täglich, wöchentlich, monatlich, jährlich usw. Wiederholungseinstellungen und Erinnerungen für Termine festlegen.

Anzeige von Schichten und Terminen ändern

Mehr → oben rechts Alle Einstellungen → Anzeigeeinstellungen können Sie die Anzeigeart und Größe von Schichten und Terminen anpassen.

4. Kollegen · Schichten teilen

Verbinden Sie sich über einen Einladungslink mit Kollegen und prüfen Sie die geteilten Schichten gemeinsam im unteren Kollegen Tab.

Link zum Teilen von Schichten an Kollegen senden
  1. Öffnen Sie unten Mehr.
  2. Wählen Sie Schicht teilen
  3. Wählen Sie Link senden
  4. und senden Sie den Einladungslink über die gewünschte App, etwa KakaoTalk oder SMS.
  5. Sobald die andere Person die Verbindung abgeschlossen hat, prüfen Sie sie im unteren Kollegen Tab.
Schichten von Kollegen anzeigen

Die Schichten verbundener Kollegen finden Sie im unteren Kollegen Tab. Zuerst werden gespeicherte Inhalte angezeigt, anschließend werden die neuesten Daten abgerufen. Beim Öffnen der Kollegenansicht oder beim Wechseln des Monats werden die neuesten geteilten Schichten erneut abgerufen.

Die Art, wie die neuesten Schichten übernommen werden, kann je nach App-Version und Funktionseinstellungen variieren.
Kollegen verwalten

Auf dem unteren Kollegen Bildschirm können Sie über die Kollegenverwaltung Kollegen hinzufügen sowie Anzeigereihenfolge, Filter und Verbindungsstatus verwalten.

5. Schichtalarm

Richten Sie für jede Schicht einen eigenen Alarm passend zu den unterschiedlichen Arbeitsbeginnzeiten ein.

Schichtalarm aktivieren
  1. Öffnen Sie unten Mehr Öffnen Sie ….
  2. Alarmeinstellungen Wählen Sie … aus.
  3. rechts neben der Schicht, für die Sie den Alarm verwenden möchten Schalter Schalten Sie ihn ein.
  4. Wenn ein Hinweis zu Berechtigungen angezeigt wird, erlauben Sie die erforderlichen Alarm- und Benachrichtigungsberechtigungen.
Alarmzeit je Schicht ändern

Mehr → Alarmeinstellungen Tippen Sie auf die gewünschte Schichtkarte, um die Alarmzeit für diese Schicht zu ändern. Die Änderungen werden ohne separate Speicherschaltfläche in den Einstellungen übernommen.

Alarmton, Vibration und Alarmbildschirm einstellen

Mehr → oben rechts Alle Einstellungen → Alarme Dort können Sie die Einstellungen für den Schichtalarm, Ton und Vibration sowie den Alarmbildschirm prüfen.

6. Startbildschirm-Widget

Auf dem Startbildschirm Ihres Telefons können Sie Ihre Schichten prüfen, ohne die App zu öffnen.

ShiftMate-Widget auf dem iPhone hinzufügen
  1. Halten Sie den iPhone-Startbildschirm gedrückt und wechseln Sie in den Bearbeitungsmodus.
  2. Widget hinzufügen Suchen Sie nach ShiftMate.
  3. Wählen Sie die gewünschte Widgetgröße und -form aus.
  4. Platzieren Sie es auf dem Startbildschirm.
ShiftMate-Widget auf Android hinzufügen
  1. Halten Sie den Startbildschirm gedrückt und Widgets Öffnen Sie das Menü.
  2. Suchen Sie ShiftMate.
  3. Fügen Sie das gewünschte Widget zum Startbildschirm hinzu.
Je nach Android-Hersteller und -Version können sich die Bezeichnung und Position des Bildschirms zum Hinzufügen von Widgets leicht unterscheiden.
Angezeigte Inhalte des Widgets einstellen

Mehr → Widget-Einstellungen Dort können Sie die anzuzeigenden Schichten und weitere Optionen für das ShiftMate-Widget einstellen. Das eigentliche Hinzufügen des Widgets zum Startbildschirm erfolgt auf dem Startbildschirm von iPhone/Android.

7. Notizen

unten Notizen Im Tab „Notizen“ verwalten Sie normale Notizen und Checklisten-Notizen.

Notiz erstellen
  1. unten Notizen Öffnen Sie den Tab.
  2. + Tippen Sie auf die Schaltfläche, um eine Notiz zu öffnen.
  3. Geben Sie Titel und Inhalt ein.
  4. unten Speichern Tippen Sie auf ….
Checklisten-Notizen verwenden

Wenn Sie zu erledigende Aufgaben nach einzelnen Punkten überprüfen möchten, können Sie die Notizart in Checklisten-Notiz ändern und Checklistenpunkte hinzufügen.

Notizen suchen und sortieren

Mit den Filter- und Sortierfunktionen der Notizliste können Sie benötigte Notizen schnell nach Kriterien wie normaler Notiz oder Checklisten-Notiz, Erledigungsstatus und Datum finden.

8. Anwesenheit & Analyse

Aufzeichnungen wie Urlaub, Krankheitsurlaub, Schulungen, Dienstreisen, Verspätungen und vorzeitiges Gehen, die unabhängig vom Dienstplan verwaltet werden sollen, werden als Anwesenheit verwaltet.

Anwesenheitsaufzeichnung hinzufügen

Wählen Sie im Schichtkalender ein Datum aus, um die Detailansicht des Datums zu öffnen, und öffnen Sie anschließend + über die Schaltfläche Anwesenheit um eine Aufzeichnung hinzuzufügen.

Um Anwesenheitsarten hinzuzufügen oder zu bearbeiten, Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Anwesenheitseinstellungen verwenden Sie diese Option.
Schichtanalyse und Anwesenheit & Abwesenheit prüfen

Mehr → Schichtanalyse können Sie Schichtmuster prüfen, Mehr → Anwesenheit & Abwesenheit können Sie Anwesenheitsaufzeichnungen nach Zeitraum prüfen. Unter „Anwesenheit & Abwesenheit“ können Sie diesen Monat · letzten Monat · letzte 3 Monate · dieses Jahr · letztes Jahr oder benutzerdefinierte Auswahl als Berichtszeitraum festlegen.

9. Konto, Daten & Einstellungen

unten Mehr und oben rechts Alle Einstellungen verwalten Sie wichtige Einstellungen und Supportmenüs.

Alle Einstellungen im Überblick

Mehr → oben rechts Alle Einstellungen Dort können Sie die folgenden Bereiche verwalten.

  • Schichten, Abwesenheit & Anwesenheit — Schichtarten, Anwesenheit, Schichtansicht
  • Alarme — Schichtalarm, Ton, Vibration
  • Kalender — Region, Wochenbeginn, anzuzeigende Kalender
  • Bildschirmeinstellungen — Anzeige und Größe von Schichten und Terminen
  • Design — Bildschirmmodus, Farben, Schriftart
  • Startbildschirm-Widget — Einstellungen für monatliche und tägliche/wöchentliche Widgets
Anmeldung und Konto

Die Anmeldung wird für die automatische Sicherung und das Teilen von Schichtdaten verwendet. Prüfen Sie vor dem Wechsel Ihres Telefons die Informationen zu dem aktuell verwendeten Konto.

Datensicherung und Wiederherstellung prüfen

Nach der Anmeldung können Sie die Sicherung und Synchronisierung unterstützter Daten sowie die Schicht teilen-Funktion nutzen. Welche Daten gesichert und wiederhergestellt werden, kann je nach App-Version und Datenart unterschiedlich sein. Prüfen Sie daher vor einem Gerätewechsel oder einer Neuinstallation der App das aktuell angemeldete Konto. Melden Sie sich auf dem neuen Gerät mit demselben Konto an.

Hilfe, Kontakt und Feedback senden

Alle Einstellungen → Hilfe & Support finden Sie FAQ, Kontakt, Feedback & Verbesserungsvorschläge und ShiftMate bewerten können Sie dort nutzen.

10. Bei Problemen

Die normale Verwendung wird in diesem Leitfaden erklärt. Informationen zu Fehlern oder unerwartetem Verhalten finden Sie unter FAQ.

  • Der Schichtalarm klingelt nicht.
  • Das Startbildschirm-Widget wird nicht aktualisiert.
  • Die Schichten von Kollegen werden nicht auf dem neuesten Stand angezeigt.
  • Der Freigabelink lässt sich nicht öffnen.
  • Es gibt ein Problem mit der Anmeldung, Authentifizierung oder Datenwiederherstellung.
  • Termine oder Feiertage werden falsch angezeigt.
