1. Erste Schritte

Sie müssen die Anleitung nicht vollständig von Anfang bis Ende lesen. Wenn Sie nur den folgenden Ablauf kennen, können Sie sofort loslegen.

ShiftMate in 5 Minuten starten
  1. Schicht-Tab am unteren Rand oben Eingeben Tippen Sie darauf, um Ihre erste Schicht einzutragen.
  2. Mehr → Alarmeinstellungen Schalten Sie dort den Schichtalarm für Ihre verwendete Schicht ein und prüfen Sie die Uhrzeit.
  3. ShiftMate auf dem Startbildschirm Ihres Smartphones Startbildschirm-Widget Fügen Sie es hinzu.
  4. Falls nötig Mehr → Schicht teilen → Link senden Senden Sie Ihren Kollegen den Einladungslink.
Empfehlung
Am Anfang Schicht eintragen → Schichtalarm → Startbildschirm-Widget Es reicht aus, zunächst nur diese Einstellungen vorzunehmen.

2. Dienstplan

Unten im Schicht-Tab tragen Sie Ihre Schichten wie D, E, N und OFF ein und prüfen sie.

Schicht eintragen

Schicht → Eingeben bearbeiten Sie den Dienstplan.

  1. Unten Schicht Öffnen Sie den Tab.
  2. Oben auf dem Bildschirm Eingeben Tippen Sie darauf.
  3. Wählen Sie im Kalender das Datum aus, für das Sie eine Schicht eintragen möchten.
  4. Tippen Sie auf die gewünschte Schicht, etwa D, E, N oder OFF.
  5. Wenn Sie mit der Eingabe fertig sind, tippen Sie oben rechts auf Speichern.
Dienstplan für einen Monat schnell fortlaufend eintragen

Im Bildschirm „Schicht eintragen“ von ShiftMate werden nicht mehrere Tage gleichzeitig ausgewählt, sondern nach dem Eintragen einer Schicht für einen Tag automatisch zum nächsten Datum weitergeschaltet. So können Sie den Dienstplan schnell für einen ganzen Monat eintragen, indem Sie beim Blick auf den Dienstplan nacheinander D → E → N → OFF auswählen.

  1. Schicht → Eingeben Öffnen Sie die Ansicht.
  2. Wählen Sie das Datum aus, an dem Sie mit der Eingabe beginnen möchten.
  3. Tippen Sie auf die Schaltfläche für die Schicht dieses Datums.
  4. Wenn die Auswahl zum nächsten Datum wechselt, wählen Sie die nächste Schicht aus.
  5. Nachdem Sie alle Schichten eingetragen haben, tippen Sie oben rechts auf Speichern.
Tip
Wenn Sie ein Datum in der Mitte ändern müssen, können Sie es im Kalender erneut auswählen und direkt mit der Eingabe fortfahren.
Schichten bearbeiten und löschen

Schicht → Eingeben Wählen Sie das zu bearbeitende Datum aus und tippen Sie auf eine andere Schicht oder Löschen Wählen Sie anschließend Speichern.

Ihre verwendeten Schichten einrichten

Mehr → Schichteinstellungen verwalten Sie Schichtnamen, Farben, Schichtzeiten und die verfügbaren Schichten.

In den Alle Einstellungen Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Schichteinstellungen können Sie ebenfalls dorthin gelangen.
Schichtanalyse anzeigen

Mehr → Schichtanalyse Hier können Sie Ihre eingetragenen Schichten nach Zeitraum anzeigen. Nutzen Sie diese Funktion, um die Anzahl und Muster der einzelnen Schichtarten zu prüfen.

3. Termine

ShiftMate zeigt persönliche Termine aus dem Gerätekalender zusammen mit Ihren Schichten an und verknüpft Funktionen zum Hinzufügen und Bearbeiten von Terminen.

Persönlichen Termin hinzufügen

Unten im Schicht-Tab wählen Sie das gewünschte Datum aus und können über die + Schaltfläche einen Termin hinzufügen. Wenn Sie den Inhalt in der Terminbearbeitungsansicht von ShiftMate eingeben, wird er im ausgewählten Gerätekalender gespeichert.

Um persönliche Termine zusammen mit dem Dienstplan zu verwenden, ist auf dem Gerät die Kalenderzugriffsberechtigung erforderlich.
Wiederkehrende Termine und Terminerinnerungen einrichten

In der Terminbearbeitungsansicht können Sie für täglich, wöchentlich, monatlich oder jährlich unter anderem Wiederholungseinstellungen sowie eine Termin- Erinnerung einrichten.

Anzeige von Schichten und Terminen ändern

Mehr → oben rechts Alle Einstellungen → Anzeigeeinstellungen Hier können Sie die Anzeigeart und Größe von Schichten und Terminen anpassen.

4. Kollegen · Schichten teilen

Verbinden Sie sich über einen Einladungslink mit Kollegen und prüfen Sie geteilte Schichten gemeinsam im unteren Kollegen Tab.

Link zum Teilen von Schichten an Kollegen senden
  1. Unten Mehr Öffnen Sie den Bereich.
  2. Schicht teilen Wählen Sie dies aus.
  3. Link senden Wählen Sie dies aus.
  4. Senden Sie den Einladungslink über die gewünschte App, etwa KakaoTalk oder SMS.
  5. Wenn die andere Person die Verbindung hergestellt hat, können Sie sie im unteren Kollegen Tab prüfen.
Schichten von Kollegen anzeigen

Die Schichten verbundener Kollegen finden Sie im unteren Kollegen Tab. Zuerst werden die gespeicherten Inhalte angezeigt, anschließend werden die neuesten Daten abgerufen. Wenn Sie die Ansicht eines Kollegen öffnen oder den Monat wechseln, werden die neuesten geteilten Schichten erneut abgerufen.

Die Aktualisierung der neuesten Schichten kann je nach App-Version und Funktionseinstellungen unterschiedlich erfolgen.
Kollegen verwalten

Unten Kollegen In der Ansicht können Sie über die Kollegenverwaltung Kollegen hinzufügen sowie Anzeigereihenfolge, Filter und Verbindungsstatus organisieren.

5. Schichtalarm

Richten Sie für jede Schicht einen eigenen Alarm entsprechend der unterschiedlichen Arbeitsbeginnzeiten ein.

Schichtalarm einschalten
  1. Unten Mehr wird geöffnet.
  2. Alarmeinstellungen aus.
  3. Rechts neben der Schicht, für die Sie den Alarm verwenden möchten, den Schalter schalten Sie ein.
  4. Wenn ein Hinweis zu Berechtigungen angezeigt wird, erlauben Sie die erforderlichen Alarm- und Benachrichtigungsberechtigungen.
Alarmzeit für eine Schicht ändern

Mehr → Alarmeinstellungen Tippen Sie auf die gewünschte Schichtkarte, um die Alarmzeit dieser Schicht zu ändern. Die Änderung wird ohne separate Speichern-Schaltfläche in den Einstellungen übernommen.

Alarmton, Vibration und Alarmbildschirm einstellen

Mehr → oben rechts Alle Einstellungen → Alarme Hier können Sie die Einstellungen für den Schichtalarm, Ton und Vibration sowie den Alarmbildschirm prüfen.

6. Startbildschirm-Widget

Sie können Ihre Schichten auf dem Startbildschirm Ihres Smartphones prüfen, ohne die App zu öffnen.

ShiftMate-Widget auf dem iPhone hinzufügen
  1. Halten Sie den iPhone-Startbildschirm gedrückt und wechseln Sie in den Bearbeitungsmodus.
  2. Widget hinzufügen Suchen Sie nach ShiftMate.
  3. Wählen Sie die gewünschte Widgetgröße und -form aus.
  4. Platzieren Sie es auf dem Startbildschirm.
ShiftMate-Widget auf Android hinzufügen
  1. Halten Sie den Startbildschirm gedrückt und Widgets öffnen Sie das Menü.
  2. Suchen Sie ShiftMate.
  3. Fügen Sie das gewünschte Widget zum Startbildschirm hinzu.
Je nach Android-Hersteller und -Version können die Bezeichnung und Position des Bildschirms zum Hinzufügen von Widgets leicht abweichen.
Anzeigeinhalte des Widgets einstellen

Mehr → Widget-Einstellungen Hier können Sie die im ShiftMate-Widget angezeigten Schichten und zugehörige Optionen einstellen. Das tatsächliche Hinzufügen des Widgets zum Startbildschirm erfolgt auf dem Startbildschirm von iPhone/Android.

7. Notizen

unten Notizen Im Tab „Notizen“ verwalten Sie normale Notizen und Checklisten-Notizen.

Eine Notiz erstellen
  1. Öffnen Sie unten den Notizen- Tab.
  2. + Tippen Sie auf die Schaltfläche, um eine Notiz zu öffnen.
  3. Geben Sie Titel und Inhalt ein.
  4. Tippen Sie unten auf Speichern.
Checklisten-Notizen verwenden

Wenn Sie die zu erledigenden Aufgaben nach Punkten prüfen möchten, können Sie die Art der Notiz in Checklisten-Notiz ändern und Checklistenpunkte hinzufügen.

Notizen suchen und sortieren

Mit den Filter- und Sortierfunktionen der Notizliste können Sie benötigte Notizen schnell nach Kriterien wie normale Notizen oder Checklisten-Notizen, Erledigungsstatus und Datum finden.

8. Anwesenheit & Analyse

Aufzeichnungen wie Urlaub, Krankheit, Schulungen, Dienstreisen, Verspätungen und vorzeitiges Gehen, die getrennt vom Dienstplan verwaltet werden sollen, werden als Anwesenheit verwaltet.

Anwesenheitsaufzeichnung hinzufügen

Wählen Sie im Schichtkalender ein Datum aus und öffnen Sie die Datumsdetailansicht. Tippen Sie anschließend auf die + Schaltfläche Anwesenheit und fügen Sie eine Aufzeichnung hinzu.

Um Anwesenheitsarten selbst hinzuzufügen oder zu bearbeiten, verwenden Sie Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Anwesenheitseinstellungen.
Schichtanalyse und Anwesenheit & Abwesenheit prüfen

Mehr → Schichtanalyse zeigt Ihnen Schichtmuster an, Mehr → Anwesenheit & Abwesenheit zeigt Ihre Anwesenheitsaufzeichnungen nach Zeitraum an. Unter „Anwesenheit & Abwesenheit“ können Sie diesen Monat · letzten Monat · letzte 3 Monate · dieses Jahr · letztes Jahr oder manuell auswählen und den Abfragezeitraum festlegen.

9. Konto, Daten & Einstellungen

Unten Mehr und oben rechts unter Alle Einstellungen verwalten Sie wichtige Einstellungen und Support-Menüs.

Alle Einstellungen erkunden

Mehr → oben rechts Alle Einstellungen Hier können Sie die folgenden Bereiche verwalten.

  • Schichten, Abwesenheit & Anwesenheit — Schichtarten, Anwesenheit, Schichtansicht
  • Alarme — Schichtalarm, Ton, Vibration
  • Kalender — Region, Wochenbeginn, anzuzeigende Kalender
  • Anzeigeeinstellungen — Anzeige und Größe von Schichten und Terminen
  • Design — Bildschirmmodus, Farben, Schriftart
  • Startbildschirm-Widget — Einstellungen für Monats-, Tages- und Wochen-Widgets
Anmeldung und Konto

Die Anmeldung wird für die automatische Sicherung und das Teilen von Schichtdaten verwendet. Prüfen Sie vor dem Wechsel Ihres Smartphones die Informationen des aktuell verwendeten Kontos.

Datensicherung und Wiederherstellung prüfen

Nach der Anmeldung können Sie die Sicherung und Synchronisierung unterstützter Daten sowie die Funktion zum Teilen von Schichten verwenden. Welche Daten gesichert und wiederhergestellt werden, kann je nach App-Version und Datenart variieren. Prüfen Sie daher vor einem Gerätewechsel oder einer Neuinstallation der App das aktuell angemeldete Konto. Melden Sie sich auf dem neuen Gerät mit demselben Konto an.

Hilfe, Kontakt und Feedback senden

Alle Einstellungen → Hilfe & Support Hier können Sie FAQ, Kontakt, Feedback & Verbesserungsvorschläge sowie ShiftMate bewerten nutzen.

10. Bei Problemen

Die normale Verwendung finden Sie in diesem Leitfaden. Bei Fehlern oder unerwartetem Verhalten lesen Sie bitte die FAQ.

  • Der Schichtalarm klingelt nicht.
  • Das Startbildschirm-Widget wird nicht aktualisiert.
  • Die Schichten von Kollegen werden nicht auf dem neuesten Stand angezeigt.
  • Der Freigabelink lässt sich nicht öffnen.
  • Es gibt ein Problem mit der Anmeldung, Authentifizierung oder Datenwiederherstellung.
  • Termine oder Feiertage werden nicht korrekt angezeigt.
