1. Erste Schritte

Sie müssen die Anleitung nicht vollständig von Anfang bis Ende lesen. Wenn Sie nur den folgenden Ablauf kennenlernen, können Sie sofort loslegen.

ShiftMate in 5 Minuten starten
  1. Schicht-Tab unten oben Eintragen tippen, um Ihre erste Schicht einzutragen.
  2. Mehr → Alarmeinstellungen aktivieren Sie den Schichtalarm für die verwendete Schicht und prüfen Sie die Uhrzeit.
  3. ShiftMate auf dem Startbildschirm Ihres Smartphones Startbildschirm-Widget hinzufügen.
  4. Falls nötig, Mehr → Schicht teilen → Link senden senden Sie Kollegen einen Einladungslink.
Empfehlung
Zu Beginn reicht es, Schicht eintragen → Schichtalarm → Startbildschirm-Widget einzurichten.

2. Dienstplan

Unten im Schicht-Tab tragen Sie Ihre Schichten wie D, E, N und OFF ein und überprüfen sie.

Schicht eintragen

Schichten → Eintragen bearbeiten Sie den Dienstplan.

  1. Öffnen Sie unten den Schicht-Tab. Tab.
  2. Tippen Sie oben auf dem Bildschirm auf Eintragen.
  3. Wählen Sie im Kalender das Datum aus, für das Sie eine Schicht eintragen möchten.
  4. Tippen Sie auf die gewünschte Schicht, zum Beispiel D, E, N oder OFF.
  5. Tippen Sie nach Abschluss der Eingabe oben rechts auf Speichern.
Einen Monatsdienstplan schnell fortlaufend eintragen

Im Eingabebildschirm von ShiftMate werden nicht mehrere Daten auf einmal ausgewählt, sondern nach der Eingabe einer Schicht für ein Datum springt die Auswahl automatisch zum nächsten Datum So können Sie den Dienstplan anhand des Plans schnell für einen ganzen Monat eingeben, indem Sie nacheinander beispielsweise D → E → N → OFF auswählen.

  1. Schichten → Eintragen Öffnen Sie
  2. Wählen Sie das Datum aus, an dem Sie mit der Eingabe beginnen möchten.
  3. Tippen Sie auf die Schicht für dieses Datum.
  4. Sobald die Auswahl zum nächsten Datum springt, tippen Sie weiter auf die nächste Schicht.
  5. Tippen Sie nach vollständiger Eingabe oben rechts auf Speichern.
Tip
Wenn Sie ein Datum in der Mitte ändern müssen, wählen Sie es im Kalender erneut aus und setzen Sie die Eingabe direkt fort.
Schichten bearbeiten und löschen

Schichten → Eintragen Wählen Sie das zu bearbeitende Datum aus und tippen Sie auf eine andere Schicht oder Löschen und anschließend auf Speichern.

Ihre verwendeten Schichten einrichten

Mehr → Schichteinstellungen verwalten Sie Schichtnamen, Farben, Schichtzeiten und die verwendeten Schichten.

In den Alle Einstellungen Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Schichteinstellungen können Sie ebenfalls dorthin gelangen.
Schichtanalyse ansehen

Mehr → Schichtanalyse Hier können Sie die eingetragenen Schichten nach Zeitraum überprüfen. Nutzen Sie diese Funktion, um Häufigkeit und Muster der einzelnen Schichtarten zu betrachten.

3. Termine

ShiftMate zeigt persönliche Termine aus dem Kalender Ihres Geräts zusammen mit den Schichten an und verknüpft Funktionen zum Hinzufügen und Bearbeiten von Terminen.

Persönlichen Termin hinzufügen

Wählen Sie unten im Schicht-Tab das gewünschte Datum aus. Anschließend können Sie über die Schaltfläche einen Termin hinzufügen. Wenn Sie die Details im Terminbearbeitungsbildschirm von ShiftMate eingeben, werden sie im ausgewählten Gerätekalender gespeichert. + Über die Schaltfläche können Sie einen Termin hinzufügen. Wenn Sie die Details im Terminbearbeitungsbildschirm von ShiftMate eingeben, werden sie im ausgewählten Gerätekalender gespeichert.

Um persönliche Termine zusammen mit dem Dienstplan zu verwenden, ist auf dem Gerät die Kalenderzugriffsberechtigung erforderlich.
Wiederkehrende Termine und Terminerinnerungen einrichten

Im Terminbearbeitungsbildschirm können Sie für täglich, wöchentlich, monatlich oder jährlich die Wiederholungseinstellungen und den Termin Alarm festlegen.

Darstellung von Schichten und Terminen ändern

Mehr → oben rechts Alle Einstellungen → Bildschirmeinstellungen können Sie Darstellung und Größe von Schichten und Terminen anpassen.

4. Kollegen · Schichten teilen

Verbinden Sie sich über einen Einladungslink mit Kollegen und sehen Sie gemeinsam geteilte Schichten im unteren Kollegen-Tab an.

Link zum Teilen von Schichten an Kollegen senden
  1. Öffnen Sie unten Mehr.
  2. Schicht teilen Wählen Sie
  3. Link senden aus.
  4. Senden Sie den Einladungslink über die gewünschte App, zum Beispiel KakaoTalk oder per SMS.
  5. Nachdem die andere Person die Verbindung abgeschlossen hat, sehen Sie sie im unteren Kollegen-Tab an.
Schichten von Kollegen ansehen

Die Schichten verbundener Kollegen sehen Sie im unteren Kollegen-Tab an. Zunächst werden gespeicherte Inhalte angezeigt, anschließend werden die neuesten Daten abgerufen. Beim Öffnen der Kollegenseite oder beim Wechseln des Monats werden die neuesten geteilten Schichten erneut abgerufen.

Die Aktualisierung der neuesten Schichten kann je nach App-Version und Funktionseinstellungen variieren.
Kollegen verwalten

Auf dem unteren Kollegen-Tab können Sie über die Funktion zur Kollegenverwaltung Kollegen hinzufügen sowie Anzeigereihenfolge, Filter und Verbindungsstatus verwalten.

5. Schichtalarm

Richten Sie für jede Schicht einen eigenen Alarm entsprechend der jeweiligen Arbeitsbeginnzeit ein.

Schichtalarm aktivieren
  1. Öffnen Sie unten Mehr wird geöffnet.
  2. Alarmeinstellungen wird ausgewählt.
  3. Rechts neben der Schicht, für die der Alarm verwendet werden soll, Schalter wird aktiviert.
  4. Wenn ein Hinweis zu Berechtigungen angezeigt wird, erlauben Sie die erforderlichen Alarm- und Benachrichtigungsberechtigungen.
Alarmzeit je Schicht ändern

Mehr → Alarmeinstellungen Tippen Sie auf die gewünschte Schichtkarte, um die Alarmzeit für diese Schicht zu ändern. Die Änderungen werden ohne separate Speicherschaltfläche in den Einstellungen übernommen.

Alarmton, Vibration und Alarmbildschirm einrichten

Mehr → oben rechts Alle Einstellungen → Alarme Dort können Sie die Einstellungen für den Schichtalarm, Ton und Vibration sowie den Alarmbildschirm prüfen.

6. Startbildschirm-Widget

Sie können Ihre Schichten auf dem Startbildschirm des Smartphones prüfen, ohne die App zu öffnen.

ShiftMate-Widget auf dem iPhone hinzufügen
  1. Halten Sie den iPhone-Startbildschirm gedrückt und wechseln Sie in den Bearbeitungsmodus.
  2. Widget hinzufügen Suchen Sie nach ShiftMate.
  3. Wählen Sie die gewünschte Widgetgröße und -form aus.
  4. Platzieren Sie es auf dem Startbildschirm.
ShiftMate-Widget auf Android hinzufügen
  1. Halten Sie den Startbildschirm gedrückt und Widgets Öffnen Sie das Menü.
  2. Suchen Sie nach ShiftMate.
  3. Fügen Sie das gewünschte Widget zum Startbildschirm hinzu.
Je nach Android-Hersteller und -Version können Bezeichnung und Position des Bildschirms zum Hinzufügen von Widgets leicht abweichen.
Anzuzeigende Widget-Inhalte einrichten

Mehr → Widget-Einstellungen Dort können Sie die anzuzeigenden Schichten und weitere Optionen des ShiftMate-Widgets festlegen. Das eigentliche Hinzufügen des Widgets zum Startbildschirm erfolgt auf dem iPhone- bzw. Android-Startbildschirm.

7. Notizen

Unten Notizen Im Tab verwalten Sie allgemeine Notizen und Checklisten-Notizen.

Notiz erstellen
  1. Unten Notizen Öffnen Sie den Tab.
  2. + Tippen Sie auf die Schaltfläche, um eine Notiz zu öffnen.
  3. Geben Sie Titel und Inhalt ein.
  4. Unten Speichern Tippen Sie darauf.
Checklisten-Notizen verwenden

Wenn Sie zu erledigende Aufgaben nach Punkten prüfen möchten, können Sie die Notizart in Checklisten-Notiz ändern und Checklistenpunkte hinzufügen.

Notizen suchen und sortieren

Mit den Filter- und Sortierfunktionen der Notizenliste können Sie benötigte Notizen schnell nach Kriterien wie allgemeine Notizen oder Checklisten-Notizen, Erledigungsstatus und Datum finden.

8. Anwesenheit & Abwesenheit · Analyse

Aufzeichnungen wie Urlaub, Krankheit, Schulung, Dienstreise, Verspätung und vorzeitiges Gehen, die unabhängig vom Dienstplan verwaltet werden müssen, werden unter Anwesenheit verwaltet.

Anwesenheitsaufzeichnung hinzufügen

Wählen Sie im Schichtkalender ein Datum aus und öffnen Sie anschließend die Datumsdetails. + Über die Schaltfläche Anwesenheit können Sie eine Aufzeichnung hinzufügen.

Wenn Sie die Arten der Anwesenheit selbst hinzufügen oder bearbeiten möchten, verwenden Sie Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Anwesenheitseinstellungen.
Schichtanalyse und Anwesenheit & Abwesenheit prüfen

Mehr → Schichtanalyse können Sie Schichtmuster prüfen, Mehr → Anwesenheit & Abwesenheit dort können Sie Anwesenheitsaufzeichnungen nach Zeitraum prüfen. Unter Anwesenheit & Abwesenheit können Sie diesen Monat · letzten Monat · letzte 3 Monate · dieses Jahr · letztes Jahr oder Benutzerdefiniert als Berichtszeitraum festlegen.

9. Konto · Daten · Einstellungen

Unten Mehr und oben rechts Alle Einstellungen verwalten Sie wichtige Einstellungen und Support-Menüs.

Alle Einstellungen entdecken

Mehr → oben rechts Alle Einstellungen Dort können Sie die folgenden Bereiche verwalten.

  • Schichten, Abwesenheit & Anwesenheit — Schichtarten, Anwesenheit, Schichtansicht
  • Alarme — Schichtalarm, Ton, Vibration
  • Kalender — Region, Wochenbeginn, anzuzeigende Kalender
  • Bildschirmeinstellungen — Anzeigeart und Größe von Schichten und Terminen
  • Design — Bildschirmmodus, Farben, Schriftart
  • Startbildschirm-Widget — Einstellungen für Monats- und Tages-/Wochen-Widgets
Anmeldung und Konto

Die Anmeldung wird für die automatische Sicherung und das Teilen von Schichtdaten verwendet. Prüfen Sie vor dem Wechsel Ihres Smartphones die Informationen zum aktuell verwendeten Konto.

Datensicherung und Wiederherstellung prüfen

Nach der Anmeldung können Sie die Sicherung und Synchronisierung unterstützter Daten sowie das Teilen von Schichten nutzen. Welche Daten gesichert und wiederhergestellt werden, kann je nach App-Version und Datenart abweichen. Prüfen Sie daher vor einem Gerätewechsel oder einer Neuinstallation der App das aktuell angemeldete Konto. Melden Sie sich auf dem neuen Gerät mit demselben Konto an.

Hilfe, Kontakt und Feedback senden

Alle Einstellungen → Hilfe & Support unter FAQ, Kontakt, Feedback & Verbesserungsvorschläge und ShiftMate bewerten stehen zur Verfügung.

10. Bei Problemen

Die normale Verwendung wird in diesem Leitfaden erklärt. Informationen zu Fehlern oder unerwartetem Verhalten finden Sie unter FAQ.

  • Der Schichtalarm ertönt nicht.
  • Das Startbildschirm-Widget wird nicht aktualisiert.
  • Die Schichten von Kollegen werden nicht auf dem neuesten Stand angezeigt.
  • Der Freigabelink lässt sich nicht öffnen.
  • Es gibt ein Problem mit der Anmeldung, Authentifizierung oder Datenwiederherstellung.
  • Die Anzeige von Terminen oder Feiertagen ist fehlerhaft.
