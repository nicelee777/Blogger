1. Erste Schritte

Sie müssen das Handbuch nicht von Anfang bis Ende lesen. Wenn Sie nur den folgenden Ablauf kennen, können Sie sofort loslegen.

ShiftMate in 5 Minuten starten
  1. Registerkarte Schicht unten oben Eingabe Tippen Sie darauf, um Ihre erste Schicht einzutragen.
  2. Mehr → Alarmeinstellungen Aktivieren Sie dort den Schichtalarm für Ihre Schicht und prüfen Sie die Uhrzeit.
  3. ShiftMate auf dem Startbildschirm Ihres Smartphones Startbildschirm-Widget hinzufügen.
  4. Falls nötig, Mehr → Schicht teilen → Link senden senden Sie Ihren Kollegen den Einladungslink.
Empfehlung
Am Anfang Schicht eintragen → Schichtalarm → Startbildschirm-Widget einzurichten, reicht völlig aus.

2. Dienstplan

Unten in der Schicht Registerkarte können Sie Ihre Schichten wie D, E, N und Off eintragen und prüfen.

Schicht eintragen

Schicht → Eingabe bearbeiten Sie den Dienstplan.

  1. Unten Schicht öffnen Sie die Registerkarte.
  2. Tippen Sie oben auf dem Bildschirm auf Eingabe.
  3. Wählen Sie im Kalender das Datum aus, für das Sie eine Schicht eintragen möchten.
  4. Tippen Sie unten auf die gewünschte Schicht, zum Beispiel D, E, N oder Off.
  5. Wenn Sie fertig sind, tippen Sie oben rechts auf Speichern.
Den Dienstplan für einen Monat schnell fortlaufend eintragen

Der Bildschirm „Schicht eintragen“ in ShiftMate ermöglicht nicht die Auswahl mehrerer Daten auf einmal, sondern verschiebt die Auswahl automatisch zum nächsten Datum, sobald Sie eine Schicht für ein Datum eingetragen haben . Sie können den Dienstplan für einen Monat schnell eintragen, indem Sie beim Blick auf den Dienstplan der Reihe nach D → E → N → Off antippen.

  1. Schicht → Eingabe öffnen.
  2. Wählen Sie das Datum aus, an dem Sie mit der Eingabe beginnen möchten.
  3. Tippen Sie auf die Schicht für dieses Datum.
  4. Wenn die Auswahl zum nächsten Datum wechselt, tippen Sie mit der nächsten Schicht weiter.
  5. Nachdem Sie alles eingegeben haben, tippen Sie oben rechts auf Speichern.
Tip
Wenn Sie ein Datum in der Mitte ändern müssen, können Sie es im Kalender erneut auswählen und direkt mit der Eingabe fortfahren.
Schichten bearbeiten und löschen

Schicht → Eingabe Wählen Sie das zu ändernde Datum aus und tippen Sie auf eine andere Schicht oder Löschen aus und tippen Sie anschließend auf Speichern.

Ihre Schichten einrichten

Mehr → Schichteinstellungen verwalten Sie Schichtnamen, Farben, Schichtzeiten und die verwendeten Schichten.

Unter Alle Einstellungen Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Schichteinstellungen können Sie ebenfalls dorthin gelangen.
Schichtanalyse anzeigen

Mehr → Schichtanalyse können Sie die eingetragenen Schichten nach Zeitraum anzeigen. Nutzen Sie diese Funktion, um die Anzahl und Muster der einzelnen Schichtarten zu prüfen.

3. Termine

ShiftMate zeigt persönliche Termine aus dem Gerätekalender zusammen mit Ihren Schichten an und verknüpft Funktionen zum Hinzufügen und Bearbeiten von Terminen.

Persönlichen Termin hinzufügen

Unten in der Schicht Registerkarte wählen Sie das gewünschte Datum aus und können über die + Schaltfläche einen Termin hinzufügen. Wenn Sie die Inhalte im Terminbearbeitungsbildschirm von ShiftMate eingeben, werden sie im ausgewählten Gerätekalender gespeichert.

Um persönliche Termine zusammen mit dem Dienstplan zu verwenden, benötigen Sie die Kalenderzugriffsberechtigung des Geräts.
Wiederkehrende Termine und Terminerinnerungen einrichten

Im Terminbearbeitungsbildschirm können Sie für tägliche, wöchentliche, monatliche oder jährliche Termine die Wiederholungseinstellungen sowie den Alarm für den Termin festlegen.

Anzeige von Schichten und Terminen ändern

Mehr → oben rechts Alle Einstellungen → Bildschirmeinstellungen können Sie die Anzeigeart und Größe von Schichten und Terminen anpassen.

4. Kollegen · Schichten teilen

Verbinden Sie sich über einen Einladungslink mit Kollegen und sehen Sie die geteilten Schichten gemeinsam in der unteren Kollegen Registerkarte.

Link zum Teilen von Schichten an Kollegen senden
  1. Unten Mehr öffnen.
  2. Schicht teilen auswählen.
  3. Link senden auswählen.
  4. Senden Sie den Einladungslink über die gewünschte App, zum Beispiel KakaoTalk oder SMS.
  5. Wenn die andere Person die Verbindung abgeschlossen hat, können Sie sie unten in der Kollegen Registerkarte sehen.
Schichten von Kollegen anzeigen

Die Schichten verbundener Kollegen finden Sie unten in der Kollegen Registerkarte. Zuerst werden gespeicherte Inhalte angezeigt, anschließend werden die neuesten Daten abgerufen. Wenn Sie den Kollegenbildschirm öffnen oder den Monat wechseln, werden die neuesten geteilten Schichten erneut abgerufen.

Die Aktualisierung der neuesten Schichten kann je nach App-Version und Funktionseinstellungen unterschiedlich erfolgen.
Kollegen verwalten

Unten in der Kollegen Registerkarte können Sie über die Kollegenverwaltung Kollegen hinzufügen sowie Anzeigereihenfolge, Filter und Verbindungsstatus organisieren.

5. Schichtalarm

Richten Sie für jede Schicht einen eigenen Schichtalarm entsprechend der unterschiedlichen Arbeitsbeginnzeiten ein.

Schichtalarm aktivieren
  1. Unten Mehr öffnen Sie.
  2. Alarmeinstellungen aus.
  3. rechts neben der Schicht, für die Sie den Alarm verwenden möchten, den Schalter ein.
  4. Wenn ein Hinweis zu Berechtigungen angezeigt wird, erlauben Sie die erforderlichen Alarm- und Benachrichtigungsberechtigungen.
Alarmzeit je Schicht ändern

Mehr → Alarmeinstellungen Wenn Sie dort auf die gewünschte Schichtkarte tippen, können Sie die Alarmzeit für diese Schicht ändern. Die Änderungen werden ohne separate Speichertaste in den Einstellungen übernommen.

Alarmton, Vibration und Alarmbildschirm einstellen

Mehr → oben rechts Alle Einstellungen → Alarme können Sie die Einstellungen für den Schichtalarm, Ton und Vibration sowie den Alarmbildschirm prüfen.

6. Startbildschirm-Widget

Auf dem Startbildschirm Ihres Telefons können Sie Ihre Schichten prüfen, ohne die App zu öffnen.

ShiftMate-Widget auf dem iPhone hinzufügen
  1. Halten Sie den iPhone-Startbildschirm gedrückt und wechseln Sie in den Bearbeitungsmodus.
  2. Widget hinzufügen suchen Sie nach ShiftMate.
  3. Wählen Sie die gewünschte Widgetgröße und -form aus.
  4. Platzieren Sie es auf dem Startbildschirm.
ShiftMate-Widget auf Android hinzufügen
  1. Halten Sie den Startbildschirm gedrückt und Widgets öffnen Sie das Menü.
  2. Suchen Sie nach ShiftMate.
  3. Fügen Sie das gewünschte Widget zum Startbildschirm hinzu.
Je nach Android-Hersteller und Version können sich die Bezeichnung und Position des Bildschirms zum Hinzufügen von Widgets leicht unterscheiden.
Anzuzeigende Widget-Inhalte einstellen

Mehr → Widget-Einstellungen können Sie die anzuzeigenden Schichten und zugehörigen Optionen im ShiftMate-Widget einstellen. Das eigentliche Hinzufügen des Widgets zum Startbildschirm erfolgt auf dem Startbildschirm von iPhone/Android.

7. Notizen

unten Notizen verwalten Sie allgemeine Notizen und Checklisten-Notizen.

Notiz erstellen
  1. unten Notizen öffnen Sie den Tab.
  2. + Tippen Sie auf die Schaltfläche, um eine Notiz zu öffnen.
  3. Geben Sie Titel und Inhalt ein.
  4. unten Speichern tippen Sie auf.
Checklisten-Notizen verwenden

Wenn Sie zu erledigende Aufgaben nach Punkten prüfen möchten, können Sie die Notizart in Checklisten-Notiz ändern und Checklisteneinträge hinzufügen.

Notizen suchen und sortieren

Mit den Filter- und Sortierfunktionen der Notizliste können Sie benötigte Notizen schnell nach Art der Notiz, Erledigungsstatus, Datum und weiteren Kriterien finden.

8. Anwesenheit & Analyse

Urlaub, Krankheit, Schulungen, Dienstreisen, Verspätungen, vorzeitiges Gehen und andere unabhängig vom Dienstplan zu verwaltende Einträge werden als Anwesenheit verwaltet.

Anwesenheitsaufzeichnung hinzufügen

Wählen Sie im Schichtkalender ein Datum aus, um die Datumsdetails zu öffnen, und + über die Schaltfläche Anwesenheit können Sie einen Eintrag hinzufügen.

Um Anwesenheitsarten selbst hinzuzufügen oder zu bearbeiten, Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Anwesenheitseinstellungen verwenden Sie diese Option.
Schichtanalyse und Anwesenheit & Abwesenheit prüfen

Mehr → Schichtanalyse können Sie Schichtmuster und unter Mehr → Anwesenheit & Abwesenheit Anwesenheitsaufzeichnungen nach Zeitraum prüfen. Unter Anwesenheit & Abwesenheit können Sie den Auswertungszeitraum auf diesen Monat · letzten Monat · letzte 3 Monate · dieses Jahr · letztes Jahr oder Benutzerdefiniert festlegen.

9. Konto, Daten & Einstellungen

unten Mehr und oben rechts Alle Einstellungen verwalten Sie wichtige Einstellungen und Supportmenüs.

Alle Einstellungen im Überblick

Mehr → oben rechts Alle Einstellungen können Sie die folgenden Bereiche verwalten.

  • Schichten, Abwesenheit & Anwesenheit — Schichtarten, Anwesenheit, Schichtbildschirm
  • Alarme — Schichtalarm, Ton, Vibration
  • Kalender — Region, Wochenbeginn, anzuzeigende Kalender
  • Anzeigeeinstellungen — Anzeigeart und Größe von Schichten und Terminen
  • Design — Anzeigemodus, Farben, Schriftart
  • Startbildschirm-Widget — Einstellungen für Monats- und Tages-/Wochen-Widgets
Anmeldung und Konto

Die Anmeldung wird für die automatische Sicherung und die Freigabe von Schichtdaten verwendet. Prüfen Sie vor dem Wechsel Ihres Telefons die Informationen des aktuell verwendeten Kontos.

Datensicherung und Wiederherstellung prüfen

Nach der Anmeldung können Sie die Sicherung und Synchronisierung unterstützter Daten sowie das Teilen von Schichten nutzen. Welche Daten gesichert und wiederhergestellt werden, kann je nach App-Version und Datenart variieren. Prüfen Sie daher vor einem Gerätewechsel oder der Neuinstallation der App das aktuell angemeldete Konto. Melden Sie sich auf dem neuen Gerät mit demselben Konto an.

Hilfe, Kontakt und Feedback senden

Alle Einstellungen → Hilfe & Support finden Sie FAQ, Kontakt, Feedback & Verbesserungsvorschläge und ShiftMate bewerten können Sie nutzen.

10. Bei Problemen

Die normale Bedienung finden Sie in diesem Leitfaden. Bei Fehlern oder unerwartetem Verhalten sehen Sie bitte in den FAQ nach.

  • Der Schichtalarm ertönt nicht.
  • Das Startbildschirm-Widget wird nicht aktualisiert.
  • Die Schichten von Kollegen werden nicht als aktuell angezeigt.
  • Der Freigabelink lässt sich nicht öffnen.
  • Es gibt ein Problem mit der Anmeldung, Authentifizierung oder Datenwiederherstellung.
  • Die Anzeige von Terminen oder Feiertagen ist fehlerhaft.
