1. Erste Schritte

Sie müssen das Handbuch nicht von Anfang bis Ende lesen. Wenn Sie nur den folgenden Ablauf kennen, können Sie sofort loslegen.

ShiftMate in 5 Minuten starten
  1. Schicht-Tab unten oben Eingeben tippen Sie, um Ihre erste Schicht einzutragen.
  2. Mehr → Alarmeinstellungen aktivieren Sie den Schichtalarm für die verwendete Schicht und prüfen Sie die Uhrzeit.
  3. Fügen Sie ShiftMate zum Startbildschirm Ihres Smartphones hinzu Startbildschirm-Widget.
  4. Falls nötig, Mehr → Schicht teilen → Link senden senden Sie Ihren Kollegen einen Einladungslink.
Empfehlung
Am Anfang reicht es, Schicht eintragen → Schichtalarm → Startbildschirm-Widget einzurichten.

2. Dienstplan

Unten im Schicht Tab können Sie Ihre Schichten wie D, E, N und OFF eintragen und überprüfen.

Schicht eintragen

Schicht → Eingeben bearbeiten Sie den Dienstplan.

  1. Öffnen Sie unten den Schicht Tab.
  2. Tippen Sie oben auf dem Bildschirm auf Eingeben.
  3. Wählen Sie im Kalender das Datum aus, für das Sie eine Schicht eintragen möchten.
  4. Tippen Sie auf die gewünschte Schicht, z. B. D, E, N oder OFF.
  5. Wenn Sie fertig sind, tippen Sie oben rechts auf Speichern.
Einen monatlichen Dienstplan schnell nacheinander eintragen

Im Bildschirm zum Eintragen von Schichten in ShiftMate werden nicht mehrere Tage gleichzeitig ausgewählt, sondern nach dem Eintragen einer Schicht für einen Tag automatisch zum nächsten Datum weitergesprungen. Sie können den Dienstplan schnell für einen ganzen Monat eintragen, indem Sie entsprechend der Reihenfolge D → E → N → OFF tippen.

  1. Schicht → Eingeben Öffnen Sie
  2. Wählen Sie das Datum aus, an dem Sie mit der Eingabe beginnen möchten.
  3. Tippen Sie auf die Schicht für dieses Datum.
  4. Wenn die Auswahl zum nächsten Datum wechselt, tippen Sie weiter auf die nächste Schicht.
  5. Wenn Sie alles eingetragen haben, tippen Sie oben rechts auf Speichern.
Tip
Wenn Sie ein Datum in der Mitte ändern müssen, können Sie es im Kalender erneut auswählen und direkt mit der Eingabe fortfahren.
Schichten bearbeiten und löschen

Schicht → Eingeben Wählen Sie das zu bearbeitende Datum aus und tippen Sie auf eine andere Schicht oder Löschen und anschließend auf Speichern.

Eigene Schichten einrichten

Mehr → Schichteinstellungen verwalten Sie Schichtnamen, Farben, Arbeitszeiten und die verwendeten Schichten.

Unter Alle Einstellungen können Sie Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Schichteinstellungen auch aufrufen.
Schichtanalyse ansehen

Mehr → Schichtanalyse Hier können Sie die eingetragenen Schichten nach Zeitraum überprüfen. Nutzen Sie diese Funktion, um die Anzahl und Muster der verschiedenen Schichtarten zu analysieren.

3. Termine

ShiftMate zeigt persönliche Termine aus dem Gerätekalender zusammen mit Ihren Schichten an und verknüpft Funktionen zum Hinzufügen und Bearbeiten von Terminen.

Persönlichen Termin hinzufügen

Wählen Sie unten im Schicht Tab das gewünschte Datum aus und tippen Sie dann auf die + Schaltfläche, um einen Termin hinzuzufügen. Wenn Sie den Inhalt im Terminbearbeitungsbildschirm von ShiftMate eingeben, wird er im ausgewählten Gerätekalender gespeichert.

Um persönliche Termine zusammen mit dem Dienstplan zu verwenden, benötigen Sie die Berechtigung für den Kalenderzugriff des Geräts.
Wiederkehrende Termine und Terminbenachrichtigungen einrichten

Im Terminbearbeitungsbildschirm können Sie für täglich, wöchentlich, monatlich, jährlich und andere Optionen die Wiederholungseinstellungen sowie die Benachrichtigung für den Termin festlegen.

Anzeige von Schichten und Terminen ändern

Mehr → oben rechts Alle Einstellungen → Anzeigeeinstellungen Hier können Sie die Anzeige und Größe von Schichten und Terminen anpassen.

4. Kollegen & Schichten teilen

Verbinden Sie sich über einen Einladungslink mit Kollegen und sehen Sie die geteilten Schichten gemeinsam im unteren Kollegen Tab an.

Link zum Teilen von Schichten an Kollegen senden
  1. Öffnen Sie unten Mehr.
  2. Wählen Sie Schicht teilen
  3. Wählen Sie Link senden
  4. und senden Sie den Einladungslink über die gewünschte App, z. B. KakaoTalk oder per SMS.
  5. Wenn die andere Person die Verbindung abgeschlossen hat, können Sie sie im unteren Kollegen Tab überprüfen.
Schichten von Kollegen ansehen

Die Schichten verbundener Kollegen finden Sie im unteren Kollegen Tab. Zuerst werden gespeicherte Inhalte angezeigt, anschließend werden die neuesten Daten abgerufen. Wenn Sie die Ansicht eines Kollegen öffnen oder den Monat wechseln, werden die neuesten geteilten Schichten erneut abgerufen.

Die Aktualisierung der neuesten Schichten kann je nach App-Version und Funktionseinstellungen unterschiedlich erfolgen.
Kollegen verwalten

Auf dem unteren Kollegen Bildschirm können Sie über die Kollegenverwaltung Kollegen hinzufügen sowie Anzeigereihenfolge, Filter und Verbindungsstatus verwalten.

5. Schichtalarm

Richten Sie für jede Schicht einen eigenen Alarm entsprechend der unterschiedlichen Arbeitsbeginnzeiten ein.

Schichtalarm aktivieren
  1. Öffnen Sie unten Mehr Öffnen Sie ….
  2. Alarmeinstellungen Wählen Sie … aus.
  3. rechts neben der Schicht, für die Sie den Alarm verwenden möchten Schalter Schalten Sie ihn ein.
  4. Wenn ein Hinweis zu Berechtigungen angezeigt wird, erlauben Sie die erforderlichen Alarm- und Benachrichtigungsberechtigungen.
Alarmzeit je Schicht ändern

Mehr → Alarmeinstellungen Tippen Sie auf die gewünschte Schichtkarte, um die Alarmzeit für diese Schicht zu ändern. Die Änderungen werden ohne separate Speichertaste in den Einstellungen übernommen.

Alarmton, Vibration und Alarmbildschirm einstellen

Mehr → oben rechts Alle Einstellungen → Alarm können Sie die Einstellungen für den Schichtalarm, Ton und Vibration sowie den Alarmbildschirm aufrufen.

6. Startbildschirm-Widget

Auf dem Startbildschirm Ihres Telefons können Sie Ihre Schichten anzeigen, ohne die App zu öffnen.

ShiftMate-Widget zum iPhone hinzufügen
  1. Halten Sie den iPhone-Startbildschirm gedrückt und wechseln Sie in den Bearbeitungsmodus.
  2. Widget hinzufügen suchen Sie nach ShiftMate.
  3. Wählen Sie die gewünschte Widgetgröße und -form aus.
  4. Platzieren Sie es auf dem Startbildschirm.
ShiftMate-Widget zu Android hinzufügen
  1. Halten Sie den Startbildschirm gedrückt und Widgets öffnen Sie das Menü.
  2. Suchen Sie nach ShiftMate.
  3. Fügen Sie das gewünschte Widget zum Startbildschirm hinzu.
Je nach Android-Hersteller und -Version können die Bezeichnung und Position des Bildschirms zum Hinzufügen von Widgets etwas abweichen.
Anzuzeigende Widget-Inhalte einstellen

Mehr → Widget-Einstellungen können Sie die anzuzeigenden Schichten und zugehörigen Optionen für das ShiftMate-Widget einstellen. Das eigentliche Hinzufügen des Widgets zum Startbildschirm erfolgt auf dem Startbildschirm von iPhone/Android.

7. Notizen

unten Notizen im Tab verwalten Sie normale Notizen und Checklisten-Notizen.

Notiz erstellen
  1. unten Notizen Öffnen Sie den Tab.
  2. + Tippen Sie auf die Schaltfläche, um eine Notiz zu öffnen.
  3. Geben Sie Titel und Inhalt ein.
  4. unten Speichern Tippen Sie auf ….
Checklisten-Notizen verwenden

Wenn Sie die zu erledigenden Aufgaben einzeln überprüfen möchten, können Sie die Art der Notiz in Checklisten-Notiz ändern und Checklisteneinträge hinzufügen.

Notizen suchen und sortieren

Mit den Filter- und Sortierfunktionen der Notizenliste können Sie benötigte Notizen schnell nach Art der Notiz, Status, Datum und weiteren Kriterien finden.

8. Anwesenheit & Analyse

Urlaub, Krankheit, Schulungen, Dienstreisen, Verspätungen und vorzeitiges Gehen werden als Anwesenheit verwaltet, wenn sie getrennt vom Dienstplan erfasst werden sollen.

Anwesenheitsaufzeichnung hinzufügen

Wählen Sie im Schichtkalender ein Datum aus, um die Datumsdetails zu öffnen, und öffnen Sie anschließend + über die Schaltfläche Anwesenheit um einen Eintrag hinzuzufügen.

Um Anwesenheitsarten selbst hinzuzufügen oder zu bearbeiten, Mehr → oben rechts Alle Einstellungen → Schichten, Abwesenheit & Anwesenheit → Anwesenheitseinstellungen verwenden Sie diese Option.
Schichtanalyse und Anwesenheit & Abwesenheit anzeigen

Mehr → Schichtanalyse können Sie Ihre Schichtmuster und unter Mehr → Anwesenheit & Abwesenheit Ihre Anwesenheitsaufzeichnungen nach Zeitraum anzeigen. Unter Anwesenheit & Abwesenheit können Sie diesen Monat · letzten Monat · letzte 3 Monate · dieses Jahr · letztes Jahr oder benutzerdefinierte Auswahl als Abfragezeitraum festlegen.

9. Konto, Daten & Einstellungen

unten Mehr und oben rechts Alle Einstellungen verwalten Sie wichtige Einstellungen und Support-Menüs.

Alle Einstellungen erkunden

Mehr → oben rechts Alle Einstellungen können Sie die folgenden Bereiche verwalten.

  • Schichten, Abwesenheit & Anwesenheit — Schichtarten, Anwesenheit, Schichtansicht
  • Alarm — Schichtalarm, Ton, Vibration
  • Kalender — Region, Wochenbeginn, anzuzeigender Kalender
  • Anzeigeeinstellungen — Anzeige und Größe von Schichten und Terminen
  • Design — Anzeigemodus, Farben, Schriftart
  • Startbildschirm-Widget — Einstellungen für monatliche und tägliche/wöchentliche Widgets
Anmeldung und Konto

Die Anmeldung wird für die automatische Sicherung und das Teilen von Schichtdaten verwendet. Prüfen Sie vor dem Wechsel Ihres Telefons die Informationen des aktuell verwendeten Kontos.

Datensicherung und Wiederherstellung prüfen

Nach der Anmeldung können Sie die Sicherung und Synchronisierung unterstützter Daten sowie die Funktion zum Teilen von Schichten nutzen. Welche Daten gesichert und wiederhergestellt werden, kann je nach App-Version und Datenart variieren. Prüfen Sie daher vor einem Gerätewechsel oder der Neuinstallation der App das aktuell angemeldete Konto. Melden Sie sich auf dem neuen Gerät mit demselben Konto an.

Hilfe, Kontakt und Feedback senden

Alle Einstellungen → Hilfe & Support finden Sie FAQ, Kontakt, Feedback & Verbesserungsvorschläge und ShiftMate bewerten zur Verfügung.

10. Bei Problemen

Die normale Verwendung wird in diesem Leitfaden erklärt. Bei Fehlern oder unerwartetem Verhalten finden Sie Hilfe in den FAQ.

  • Der Schichtalarm klingelt nicht.
  • Das Startbildschirm-Widget wird nicht aktualisiert.
  • Die Schichten von Kollegen werden nicht auf dem neuesten Stand angezeigt.
  • Der Freigabelink lässt sich nicht öffnen.
  • Es gibt ein Problem mit der Anmeldung, Authentifizierung oder Datenwiederherstellung.
  • Die Anzeige von Terminen oder Feiertagen ist fehlerhaft.
