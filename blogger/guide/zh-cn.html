1. 开始使用

无需从头到尾阅读整份说明。掌握下面的流程后即可立即开始使用。

5分钟开始使用 ShiftMate
  1. 在底部的班次标签中点击顶部的输入，输入第一个班次。
  2. 前往显示更多 → 提醒设置，开启所用班次的上班提醒并确认时间。
  3. 将 ShiftMate 主屏幕小组件添加到手机主屏幕。
  4. 如有需要，前往显示更多 → 共享班次 → 发送链接，向同事发送邀请链接。
推荐
刚开始时，只设置输入班次 → 上班提醒 → 主屏幕小组件就足够了。

2. 班次表

在底部的班次标签中输入并确认自己的轮班班次，如 D、E、N、Off 等。

输入班次

前往班次 → 输入编辑班次表。

  1. 打开底部的班次标签。
  2. 点击屏幕顶部的输入。
  3. 在日历中选择要输入的日期。
  4. 点击下方 D、E、N、Off 等所需的班次按钮。
  5. 输入完成后，点击右上角的保存。
快速连续输入一个月的班次表

ShiftMate 的班次输入界面不是一次选择多个日期， 而是采用在某一天输入班次后，选择位置自动移动到下一天的方式。 查看班次表后，按 D → E → N → Off 的顺序点击，即可快速输入整个月的班次。

  1. 打开班次 → 输入。
  2. 选择开始输入的日期。
  3. 点击该日期的班次按钮。
  4. 选择标记移动到下一天后，继续点击下一个班次。
  5. 全部输入后，点击右上角的保存。
提示
如果需要修改中间的日期，可以在日历中重新选择该日期并继续输入。
修改·删除班次

在班次 → 输入中选择要修改的日期，点击其他班次，或选择删除，然后点击保存。

设置我使用的班次

在显示更多 → 班次设置中管理班次名称、颜色、班次时间以及要使用的班次。

也可以在全部设置中通过显示更多 → 右上角全部设置 → 班次及服务 → 班次设置进入。
查看班次分析

在显示更多 → 班次分析中按时间段查看已输入的班次。可用于查看各班次类型的次数和模式。

3. 日程

ShiftMate 会将设备日历中的个人日程与班次一同显示，并连接日程添加和修改功能。

添加个人日程

在底部的班次标签中选择所需日期，然后使用+按钮添加日程。根据设备和操作系统的不同，可能会打开系统日历界面。

如果要将个人日程与班次表一同查看，需要获得设备的日历访问权限。
设置重复日程和日程提醒

在日程编辑界面中，可以设置每天、每周、每月、每年等重复设置以及日程提醒。

更改班次·日程的显示方式

在显示更多 → 右上角全部设置 → 屏幕设置中，可以调整班次和日程的显示方式及大小。

4. 同事·共享班次

通过邀请链接与同事连接，并在底部的同事标签中共同查看共享的班次。

向同事发送共享班次链接
  1. 打开底部的显示更多。
  2. 选择共享班次。
  3. 选择发送链接。
  4. 使用 KakaoTalk、短信等所需应用发送邀请链接。
  5. 对方完成连接后，在底部的同事标签中查看。
查看同事班次

在底部的同事标签中查看已连接同事的班次。应用会先显示已保存的内容，然后确认最新数据；进入同事页面或切换月份时，会确认服务器上的最新共享班次。

同事更改班次后立即自动传送到画面的实时接收功能，是单独的功能。
管理同事

在底部的同事页面中使用同事管理功能，可以添加同事，或整理显示顺序、筛选条件和连接状态。

5. 上班提醒

根据每种班次不同的上班时间，分别设置班次提醒。

开启上班提醒
  1. 打开底部的显示更多。
  2. 选择提醒设置。
  3. 打开要使用提醒的班次右侧的开关。
  4. 出现权限提示时，允许所需的提醒和通知权限。
更改各班次的提醒时间

在显示更多 → 提醒设置中点击所需的班次卡片，即可更改该班次的提醒时间。更改内容无需点击单独的保存按钮，便会反映到设置中。

设置提醒音·振动·提醒界面

在显示更多 → 右上角全部设置 → 提醒中，可以查看上班提醒、声音和振动、提醒界面的相关设置。

提醒没有响吗？查看上班提醒问题解决方法 →

6. 主屏幕小组件

无需打开应用，即可在手机主屏幕上查看班次。

在 iPhone 上添加 ShiftMate 小组件
  1. 长按 iPhone 主屏幕，进入编辑状态。
  2. 在添加小组件中搜索 ShiftMate。
  3. 选择所需的小组件大小和样式。
  4. 将其放置到主屏幕上。
在 Android 上添加 ShiftMate 小组件
  1. 长按主屏幕，打开小组件菜单。
  2. 找到 ShiftMate。
  3. 将所需的小组件添加到主屏幕。
根据 Android 制造商和版本的不同，添加小组件界面的名称和位置可能略有不同。
设置小组件的显示内容

在显示更多 → 小组件设置中，可以设置 ShiftMate 小组件中显示的班次及相关选项。将小组件实际添加到主屏幕的操作，需要在 iPhone/Android 的主屏幕中进行。

7. 备忘录

在底部的备忘录标签中管理普通备忘录和清单备忘录。

创建备忘录
  1. 打开底部的备忘录标签。
  2. 点击+按钮打开备忘录。
  3. 填写标题和内容。
  4. 点击底部的保存。
使用清单备忘录

如果想逐项确认待办事项，可以将备忘录类型改为清单备忘录，然后添加检查项目。

查找·整理备忘录

使用备忘录列表的筛选和排序功能，可以根据普通备忘录·清单备忘录、完成状态、日期等条件快速找到所需备忘录。

8. 服务·分析

将年假、病假、培训、出差、迟到、早退等需要与班次表分开管理的记录归入服务管理。

添加服务记录

在班次日历中选择日期，打开日期详情页面后，点击+按钮并选择服务，即可添加记录。

如果要添加或修改服务类型本身，请使用显示更多 → 右上角全部设置 → 班次及服务 → 服务设置。
查看班次分析·服务状态

在显示更多 → 班次分析中查看班次模式，在显示更多 → 服务状态中按时间段查看服务记录。在服务状态中，可以选择本月·上月·最近3个月·今年等查询期间。

9. 账户·数据·设置

在底部的显示更多和右上角的全部设置中管理主要设置和支持菜单。

浏览全部设置

在显示更多 → 右上角全部设置中，可以管理以下区域。

  • 班次及服务 — 班次类型、服务、班次界面
  • 提醒 — 上班提醒、声音、振动
  • 日历 — 地区、每周开始日、要显示的日历
  • 屏幕设置 — 班次·日程的显示方式和大小
  • 主题 — 屏幕模式、颜色、字体
  • 主屏幕小组件 — 月度·每日/每周小组件设置
登录和账户

登录用于使用班次数据自动备份和共享功能。更换手机前，请确认当前使用的账户信息。

确认数据备份·恢复

登录后，班次、备忘录、服务等支持的数据会按照账户保存。重新安装或更换设备前，请确认网络连接状态和登录账户，并在新设备上使用相同账户登录。

发送帮助·咨询·意见

在全部设置 → 帮助与支持中，可以使用常见问题、联系我们、意见与改进建议、评价 ShiftMate。

10. 遇到问题时

正常使用方法请在本指南中确认，错误或未预期的行为请查看常见问题。

  • 上班提醒没有响。
  • 主屏幕小组件没有更新。
  • 同事的班次没有显示为最新状态。
  • 共享链接无法打开。
  • 登录·身份验证或数据恢复出现问题。
  • 日程或节假日显示异常。
