1. 开始使用

无需从头到尾阅读整份说明。掌握以下流程即可立即开始使用。

5分钟开始使用 ShiftMate
  1. 底部的班次选项卡中，点击顶部的 输入，输入第一个班次。
  2. 更多 → 闹钟设置中开启所用班次的上班闹钟，并确认时间。
  3. 在手机主屏幕上添加 ShiftMate 主屏幕小组件。
  4. 如有需要，可通过 更多 → 共享班次 → 发送链接向同事发送邀请链接。
推荐
开始时只需设置 输入班次 → 上班闹钟 → 主屏幕小组件即可。

2. 班表

底部的 班次 选项卡中输入并查看 D、E、N、OFF 等轮班班次。

输入班次

班次 → 输入中编辑班表。

  1. 打开底部的 班次 选项卡。
  2. 点击屏幕顶部的 输入。
  3. 在日历中选择要输入的日期。
  4. 点击下方所需的班次按钮，如 D、E、N、OFF。
  5. 输入完成后，点击右上角的 保存。
快速连续输入一个月的班表

ShiftMate 的输入班次界面不是一次选择多个日期，而是 输入某天的班次后，选择位置会自动移动到下一天。查看班表并按 D → E → N → OFF 的顺序点击，即可快速输入一个月的班次。

  1. 班次 → 输入。
  2. 选择开始输入的日期。
  3. 点击该日期的班次按钮。
  4. 选择标记移动到下一天后，继续点击下一个班次。
  5. 全部输入后，点击右上角的 保存。
Tip
如需修改中间日期，可在日历中重新选择该日期并继续输入。
修改·删除班次

班次 → 输入中选择要修改的日期，点击其他班次或选择 删除，然后点击 保存。

设置所使用的班次

更多 → 班次设置中管理班次名称、颜色、班次时间以及要使用的班次。

在所有设置中，还可以通过 更多 → 右上角的所有设置 → 班次、考勤与请假 → 班次设置进入。
查看班次分析

更多 → 班次分析中按时间段查看已输入的班次。可用于查看各班次类型的次数和规律。

3. 日程

ShiftMate 会将设备日历中的个人日程与班次一起显示，并连接日程添加和编辑功能。

添加个人日程

在底部的 班次 选项卡中选择所需日期，然后可通过 + 按钮添加日程。在 ShiftMate 的日程编辑界面填写内容后，会保存到所选设备日历中。

如需将个人日程与班表一起使用，需要设备的 日历访问权限。
设置重复日程和日程提醒

在日程编辑界面中，可以设置每天、每周、每月、每年等 重复设置以及日程 提醒。

更改班次·日程的显示方式

更多 → 右上角的所有设置 → 屏幕设置中调整班次和日程的显示方式与大小。

4. 同事·共享班次

通过邀请链接与同事建立连接，并在底部的 同事 选项卡中一起查看共享的班次。

向同事发送共享班次链接
  1. 打开底部的 更多。
  2. 选择共享班次
  3. 。选择
  4. 使用 KakaoTalk、短信等所需应用发送邀请链接。
  5. 对方完成连接后，在底部的 同事 选项卡中查看。
查看同事班次

已连接同事的班次可在底部的 同事 选项卡中查看。系统会先显示已保存的内容，然后确认最新数据； 进入同事页面或切换月份时，会重新确认最新共享班次。

最新班次的同步方式可能因应用版本和功能设置而异。
管理同事

在底部的 同事 页面中使用同事管理功能，可添加同事或整理显示顺序、筛选条件和连接状态。

5. 上班闹钟

根据每种班次不同的上班时间设置班次闹钟。

开启上班闹钟
  1. 底部的 更多打开。
  2. 闹钟设置选择
  3. 要使用闹钟的班次右侧的 开关打开。
  4. 出现权限提示时，请允许所需的闹钟和通知权限。
更改各班次的闹钟时间

更多 → 闹钟设置在 中点击所需的班次卡片，即可更改该班次的闹钟时间。更改内容无需点击单独的保存按钮，便会应用到设置中。

设置闹钟铃声、振动和闹钟界面

更多 → 右上角所有设置 → 闹钟在 中可以查看上班闹钟、声音和振动以及闹钟界面的相关设置。

闹钟没有响吗？查看上班闹钟问题解决方法 →

6. 主屏幕小组件

无需打开应用，即可在手机主屏幕上查看班次。

在 iPhone 上添加 ShiftMate 小组件
  1. 长按 iPhone 主屏幕，进入编辑模式。
  2. 添加小组件在 中搜索 ShiftMate。
  3. 选择所需的小组件大小和样式。
  4. 将其放置在主屏幕上。
在 Android 上添加 ShiftMate 小组件
  1. 长按主屏幕，然后打开 小组件 菜单。
  2. 找到 ShiftMate。
  3. 将所需的小组件添加到主屏幕。
根据 Android 制造商和版本的不同，添加小组件界面的名称和位置可能略有差异。
设置小组件显示内容

更多 → 小部件设置在 中可以设置要在 ShiftMate 小组件中显示的班次及相关选项。实际将小组件添加到主屏幕的操作，请在 iPhone/Android 的主屏幕上进行。

7. 备忘录

底部 备忘录 在 标签页中管理普通备忘录和检查清单备忘录。

创建备忘录
  1. 底部 备忘录 打开 标签页。
  2. + 点击按钮打开备忘录。
  3. 填写标题和内容。
  4. 底部 保存点击。
使用检查清单备忘录

如果想逐项查看需要完成的事项，可以将备忘录类型更改为 检查清单备忘录，然后添加检查项目。

查找和排序备忘录

利用备忘录列表的筛选和排序功能，可以根据普通备忘录、检查清单备忘录、完成状态、日期等条件快速找到所需备忘录。

8. 考勤与分析

将年假、病假、培训、出差、迟到、早退等需要与班表分开管理的记录归入考勤管理。

添加考勤记录

在班次日历中选择日期，打开日期详情界面，然后在 + 按钮中 考勤选择，即可添加记录。

如果要添加或修改考勤类型本身，请使用 更多 → 右上角所有设置 → 班次、考勤与请假 → 考勤设置。
查看班次分析和考勤概况

更多 → 班次分析中可以查看班次模式， 更多 → 考勤概况中可以按期间查看考勤记录。在考勤概况中，可以选择 本月·上月·最近 3 个月·今年·去年 或 自定义选择来设置查询期间。

9. 账户、数据与设置

底部 更多和右上角的 所有设置用于管理主要设置和支持菜单。

浏览所有设置

更多 → 右上角所有设置中可以管理以下区域。

  • 班次、考勤与请假 — 班次类型、考勤、班次界面
  • 闹钟 — 上班闹钟、声音、振动
  • 日历 — 地区、每周开始日、要显示的日历
  • 界面设置 — 班次和日程的显示方式与大小
  • 主题 — 界面模式、颜色、字体
  • 主屏幕小组件 — 月度、每日/每周小组件设置
登录和账户

登录用于使用班次数据自动备份和共享功能。更换手机前，请确认当前使用的账户信息。

确认数据备份和恢复

登录后可以使用受支持数据的备份与同步以及共享班次功能。备份和恢复的对象可能因应用版本和数据类型而异，因此在更换设备或重新安装应用前，请确认当前登录的账户。请在新设备上使用同一账户登录。

发送帮助请求、咨询和意见

所有设置 → 帮助与支持中可以使用 FAQ、联系我们、意见与改进建议、评价 ShiftMate。

10. 遇到问题时

正常使用方法请参阅本指南，遇到错误或意外行为时，请在 FAQ中查看解决方法。

  • 上班闹钟没有响。
  • 主屏幕小组件没有更新。
  • 同事的班次没有显示为最新状态。
  • 共享链接无法打开。
  • 登录、身份验证或数据恢复出现问题。
  • 日程或节假日显示异常。
