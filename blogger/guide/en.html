1. Getting started

You don't need to read the guide from beginning to end. Learn the flow below and you can start using it right away.

Start using ShiftMate in 5 minutes
  1. the Shift tab at the bottom at the top Input to enter your first shift.
  2. More → Alarm Settings to turn on the Work Alarm for the shifts you use and check the time.
  3. Add ShiftMate's Home Widget to your phone's home screen.
  4. If needed, More → Share Shift → Send link to send an invitation link to a coworker.
Recommended
At first, Input Shift → Work Alarm → Home Widget is all you need to set up.

2. Shift Schedule

At the bottom, Shift enter and check your shifts, such as D, E, N, and Off, in the tab.

Input shifts

Shift → Input to edit your Shift Schedule.

  1. Open the Shift tab at the bottom.
  2. At the top of the screen, Input Tap.
  3. Select the date to enter.
  4. Tap the desired shift button below, such as D, E, N, or Off.
  5. When you're finished entering shifts, tap Save in the upper-right corner.
Enter a month's Shift Schedule quickly and continuously

ShiftMate's shift input screen does not let you select multiple dates at once; when you enter a shift for one date, the selection automatically moves to the next date so you can quickly enter a month's shifts in order, such as D → E → N → Off, while viewing your Shift Schedule.

  1. Shift → Input Open it.
  2. Select the date on which to start entering shifts.
  3. Tap the shift button for that date.
  4. When the selection moves to the next date, continue tapping the next shift.
  5. After entering them all, tap Save in the upper-right corner.
Tip
If you need to edit a date in the middle, select that date again on the calendar and continue entering it.
Edit or delete shifts

Shift → Input select the date to edit, tap a different shift, or select Delete and then Save.

Set up the shifts you use

More → Shift Settings to manage shift names, colors, shift times, and the shifts you use.

In All Settings, More → All Settings in the upper-right corner → Shifts, Time Off & Attendance → Shift Settings is another way to access it.
Check Shift Analysis

More → Shift Analysis to view entered shifts by period. Use it to review the number and patterns of each shift type.

3. Schedule

ShiftMate displays personal events from your device calendar alongside shifts and connects to event adding and editing features.

Add a personal schedule

At the bottom, Shift select the desired date in the tab, then + you can add a schedule from the button. Entering details in ShiftMate's schedule editing screen saves them to the selected device calendar.

To use personal schedules with your Shift Schedule, your device's calendar access permission is required.
Set recurring schedules and schedule reminders

On the schedule editing screen, you can set recurrence settings such as daily, weekly, monthly, or yearly, along with a schedule's reminder.

Change how shifts and schedules are displayed

More → All Settings in the upper-right corner → Display Settings to adjust the display method and size of shifts and schedules.

4. Coworkers · Share Shifts

Connect with coworkers using an invitation link and view shared shifts together in the bottom Coworkers tab.

Send a Shift-sharing link to a coworker
  1. At the bottom, open More
  2. . Select
  3. Send link.
  4. Send the invitation link using the app you want, such as KakaoTalk or text messages.
  5. After the other person completes the connection, check it in the bottom Coworkers tab.
Check Coworker Shifts

Shifts from connected coworkers are available in the bottom Coworkers tab. Saved content is shown first, followed by a check for the latest data. When you open a coworker's screen or change the month, the latest shared shifts are checked again.

How the latest shifts are applied may vary depending on the app version and feature settings.
Manage coworkers

At the bottom, Coworkers use the coworker management features to add coworkers or organize their display order, filters, and connection status.

5. Work Alarm

Set an alarm for each shift according to the different start times for each shift type.

Turn on the Work Alarm
  1. At the bottom, open More Open it.
  2. Alarm Settings Select it.
  3. To the right of the shift for which you want to use an alarm switch Turn it on.
  4. When a permissions notice appears, allow the required alarm and notification permissions.
Changing alarm times by shift

More → Alarm Settings Tap the desired shift card to change that shift’s alarm time. Changes are applied in Settings without a separate Save button.

Setting the alarm sound, vibration, and alarm screen

More → All Settings in the upper right → Alarm You can check settings related to the Work Alarm, sound and vibration, and the alarm screen.

Is your alarm not ringing?View solutions for Work Alarm issues →

6. Home Widget

Check your shifts from your phone’s home screen without opening the app.

Adding the ShiftMate widget to iPhone
  1. Long-press the iPhone home screen and enter edit mode.
  2. Add Widget Search for ShiftMate.
  3. Select the desired widget size and style.
  4. Place it on the home screen.
Adding the ShiftMate widget to Android
  1. Long-press the home screen and Widgets Open the menu.
  2. Find ShiftMate.
  3. Add the desired widget to the home screen.
The name and location of the widget-addition screen may vary slightly depending on the Android manufacturer and version.
Setting what appears in the widget

More → Widget Settings You can set the shifts and related options to display in the ShiftMate widget. To actually add the widget to the home screen, use the iPhone/Android home screen.

7. Notes

Bottom Notes Manage regular notes and checklist notes in the bottom Notes tab.

Creating a note
  1. Bottom Notes Open the tab.
  2. + Tap the button to open a note.
  3. Enter a title and content.
  4. Bottom Save Tap it.
Using checklist notes

If you want to review tasks you need to do item by item, change the note type to Checklist note and add checklist items.

Finding and sorting notes

Use the filters and sorting features in the note list to quickly find the notes you need by conditions such as regular notes or checklist notes, completion status, and date.

8. Attendance & Analysis

Manage records such as annual leave, sick leave, training, business trips, lateness, and early departure as Attendance, separately from the Shift Schedule.

Adding an attendance record

Select a date in the shift calendar to open the date details screen, then + From the button Attendance Select it to add a record.

To add or edit attendance types themselves, More → All Settings in the upper right → Shifts, Time Off & Attendance → Attendance Settings Use this.
Checking Shift Analysis and Attendance & Leave

More → Shift Analysis to check shift patterns, and More → Attendance & Leave to check attendance records by period. In Attendance & Leave, you can set the date range to This month · Last month · Last 3 months · This year · Last year or Custom selection to set the period to view.

9. Account, Data & Settings

Bottom More and the upper-right All Settings Manage key settings and support menus here.

Exploring All Settings

More → All Settings in the upper right You can manage the following areas here.

  • Shifts, Time Off & Attendance — Shift types, attendance, and shift screen
  • Alarm — Work Alarm, sound, and vibration
  • Calendar — Region, first day of the week, and calendars to display
  • Display Settings — How shifts and schedules are displayed and their size
  • Theme — Screen mode, colors, and font
  • Home Widget — Monthly and daily/weekly widget settings
Login and account

Login is used for automatic backup and sharing of shift data. Before changing phones, make sure you know the account information you currently use.

Checking data backup and restoration

After logging in, you can use backup and synchronization for supported data, as well as shift sharing. The data covered by backup and restoration may vary depending on the app version and data type, so check the account you are currently logged in to before changing devices or reinstalling the app. Log in with the same account on your new device.

Sending help requests, inquiries, and feedback

All Settings → Help & support You can access FAQ, Contact us, Feedback & improvements, and Rate ShiftMate here.
