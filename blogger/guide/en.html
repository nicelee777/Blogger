1. Get started

You don’t need to read the guide from beginning to end. Learn the flow below and you can start using it right away.

Get started with ShiftMate in 5 minutes
  1. the Shift tab at the bottom at the top Input to enter your first Shift.
  2. More → Alarm Settings to turn on the Work Alarm for your Shift and check the time.
  3. ShiftMate on your phone’s home screen Home Widget Add it.
  4. If needed, More → Share Shift → Send link to send an invitation link to a coworker.
Recommended
At first, Input Shift → Work Alarm → Home Widget is all you need to set up.

2. Shift Schedule

At the bottom, Shift enter and check your shifts, such as D, E, N, and Off, in the Shift tab.

Input Shift

Shift → Input to edit your Shift Schedule.

  1. At the bottom, Shift Open the tab.
  2. At the top of the screen, Input Tap it.
  3. Select the date to enter.
  4. Tap the desired Shift button, such as D, E, N, or Off, below.
  5. When you’re finished entering shifts, tap Save in the upper-right corner.
Enter a monthly Shift Schedule quickly and consecutively

The ShiftMate Input Shift screen does not let you select multiple dates at once; when you enter a Shift for one date, the selection automatically moves to the next date You can quickly enter a month of Shifts by tapping them in order, such as D → E → N → Off, while viewing your Shift Schedule.

  1. Shift → Input Open it.
  2. Select the date on which to start entering shifts.
  3. Tap the Shift button for that date.
  4. When the selection moves to the next date, continue tapping the next Shift.
  5. After entering them all, tap Save in the upper-right corner.
Tip
If you need to edit a date in the middle, select that date again on the calendar and continue entering it.
Edit or delete Shifts

Shift → Input select the date to edit and tap another Shift, or select Delete then tap Save.

Set up the Shifts you use

More → Shift Settings to manage Shift names, colors, Shift hours, and the Shifts you use.

In All Settings, More → All Settings in the upper-right corner → Shifts, Time Off & Attendance → Shift Settings You can also access it this way.
Check Shift Analysis

More → Shift Analysis to review entered Shifts by period. Use it to see the number of Shifts by type and identify patterns.

3. Schedule

ShiftMate shows personal events from your device calendar together with your Shifts and connects to features for adding and editing events.

Add a personal schedule

At the bottom, Shift select the desired date in the tab, then + you can add a schedule from the button. Enter details in ShiftMate’s schedule editing screen, and they will be saved to the selected device calendar.

To use personal schedules together with your Shift Schedule, your device’s calendar access permission is required.
Set recurring schedules and schedule reminders

On the schedule editing screen, you can set recurrence settings such as daily, weekly, monthly, or yearly, as well as schedule reminders.

Change how Shifts and schedules are displayed

More → All Settings in the upper-right corner → Screen Settings to adjust the display style and size of Shifts and schedules.

4. Coworkers · Share Shifts

Connect with coworkers using an invitation link and view shared Shifts together in the bottom Coworkers tab.

Send a Shift-sharing link to a coworker
  1. At the bottom, More Open it.
  2. Share Shift Select it.
  3. Send link Select it.
  4. Send the invitation link using the app you want, such as KakaoTalk or text messaging.
  5. When the other person completes the connection, check it in the bottom Coworkers tab.
Check Coworker Shifts

Shifts from connected coworkers can be viewed in the bottom Coworkers tab. Saved content is shown first, followed by a check for the latest data. When you open a coworker’s screen or change the month, the latest shared Shifts are checked again.

How the latest Shifts are reflected may vary depending on the app version and feature settings.
Manage coworkers

At the bottom, Coworkers use coworker management to add coworkers or organize their display order, filters, and connection status.

5. Work Alarm

Set a Work Alarm for each Shift according to its different start time.

Turn on the Work Alarm
  1. At the bottom, More Open it.
  2. Alarm Settings Select it.
  3. On the right of the shift for which you want to use an alarm, switch Turn it on.
  4. When a permission prompt appears, allow the required alarm and notification permissions.
Change the alarm time for each shift

More → Alarm Settings Tap the desired shift card to change that shift’s alarm time. Changes are applied to the settings without a separate Save button.

Set the alarm sound, vibration, and alarm screen

More → All Settings in the top right → Alarm You can review settings related to the Work Alarm, sound and vibration, and the alarm screen.

Is your alarm not ringing?View Work Alarm troubleshooting →

6. Home Widget

Check your shifts from your phone’s Home screen without opening the app.

Add a ShiftMate widget to iPhone
  1. Press and hold the iPhone Home screen, then enter edit mode.
  2. Add Widget Search for ShiftMate.
  3. Select the desired widget size and style.
  4. Place it on the Home screen.
Add a ShiftMate widget to Android
  1. Press and hold the Home screen, then Widgets Open the menu.
  2. Find ShiftMate.
  3. Add the desired widget to the Home screen.
The name and location of the widget-addition screen may vary slightly depending on the Android manufacturer and version.
Set the content displayed in the widget

More → Widget Settings You can set the shifts and related options displayed in the ShiftMate widget. To actually add the widget to the Home screen, use the iPhone/Android Home screen.

7. Notes

Bottom Notes Manage regular notes and checklist notes from the Notes tab.

Create a note
  1. Bottom Notes Open the tab.
  2. + Tap the button to open a note.
  3. Enter a title and content.
  4. Bottom Save Tap it.
Use checklist notes

If you want to review tasks by item, change the note type to checklist note and add checklist items.

Find and sort notes

Use the filters and sorting features in the note list to quickly find the notes you need by type—regular or checklist—completion status, date, and other criteria.

8. Attendance & Analysis

Manage records such as annual leave, sick leave, training, business trips, late arrivals, and early departures separately from the Shift Schedule as Attendance.

Add an Attendance record

Select a date in the shift calendar to open the date details screen, then + From the button Attendance Select it to add a record.

To add or edit Attendance types themselves, More → All Settings in the top right → Shifts, Time Off & Attendance → Attendance Settings use this path.
View Shift Analysis and Attendance & Leave

More → Shift Analysis to review shift patterns, and More → Attendance & Leave to review Attendance records by period. In Attendance & Leave, This month · Last month · Last 3 months · This year · Last year or Custom selection can be used to set the date range.

9. Account, Data & Settings

Bottom More and the top-right All Settings are where you manage key settings and support menus.

Explore All Settings

More → All Settings in the top right is where you can manage the following areas.

  • Shifts, Time Off & Attendance — Shift types, Attendance, and the shift screen
  • Alarm — Work Alarm, sound, and vibration
  • Calendar — Region, first day of the week, and calendars to display
  • Display settings — How shifts and schedules are displayed and their size
  • Theme — Screen mode, colors, and font
  • Home Widget — Monthly and daily/weekly widget settings
Login and account

Login is used for automatic backup and sharing of shift data. Before changing phones, make sure you know the account currently in use.

Check data backup and restoration

When logged in, you can use backup and synchronization for supported data, as well as shift sharing. The data covered by backup and restoration may vary by app version and data type, so check the account currently in use before changing devices or reinstalling the app. Log in with the same account on the new device.

Send help requests and feedback

All Settings → Help & support provides access to FAQ, Contact us, Feedback & improvements, and Rate ShiftMate.
