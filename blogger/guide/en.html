1. Get started

You don't need to read the entire guide from beginning to end. Learn the flow below and you can start using it right away.

Start using ShiftMate in 5 minutes
  1. the Shift tab at the bottom at the top Input to enter your first shift.
  2. More → Alarm Settings to turn on the Work Alarm for the shifts you work and check the time.
  3. Add ShiftMate to your phone's Home Widget on the home screen.
  4. If needed, More → Share Shift → Send link to send an invitation link to a coworker.
Recommended
At first, Input Shift → Work Alarm → Home Widget is all you need to set up.

2. Shift Schedule

the bottom Shift Enter and review your shifts, such as D, E, N, and Off, in the tab.

Enter Shifts

Shift → Input to edit your Shift Schedule.

  1. Open the Shift tab at the bottom.
  2. At the top of the screen, Input Tap
  3. Select the date to enter.
  4. Tap the desired shift button below, such as D, E, N, or Off.
  5. When you're done entering shifts, tap Save in the upper right.
Enter a month's Shift Schedule quickly and consecutively

ShiftMate's Input Shift screen does not let you select multiple dates at once; when you enter a shift for one date, the selection automatically moves to the next date You can quickly enter a month's shifts in order while viewing the Shift Schedule, tapping D → E → N → Off.

  1. Shift → Input Open
  2. Select the date to start entering.
  3. Tap the shift button for that date.
  4. When the selection moves to the next date, continue tapping the next shift.
  5. After entering them all, tap Save in the upper right.
Tip
If you need to edit a date in the middle, select that date again on the calendar and continue entering it.
Edit or Delete Shifts

Shift → Input select the date to edit, tap a different shift, or select Delete and then tap Save.

Set up the shifts you use

More → Shift Settings to manage shift names, colors, shift hours, and the shifts you use.

In All Settings, More → All Settings in the upper right → Shifts, Time Off & Attendance → Shift Settings is another way to access it.
Check Shift Analysis

More → Shift Analysis to review entered shifts by period. Use it to examine counts and patterns by shift type.

3. Schedules

ShiftMate displays personal events from your device calendar alongside shifts and connects to features for adding and editing events.

Add a personal schedule

At the bottom, Shift select the desired date in the tab, then + you can add a schedule from the button. Enter details in ShiftMate's schedule editor, and they will be saved to the selected device calendar.

To use personal schedules alongside your Shift Schedule, your device's calendar access permission is required.
Set recurring schedules and schedule reminders

In the schedule editor, you can set recurrence settings such as daily, weekly, monthly, or yearly, as well as schedule reminders.

Change how shifts and schedules are displayed

More → All Settings in the upper right → Screen Settings to adjust the display style and size of shifts and schedules.

4. Coworkers · Share Shifts

Connect with coworkers using an invitation link and view shared shifts together in the bottom Coworkers tab.

Send a Shift Sharing Link to a Coworker
  1. At the bottom, More Open
  2. Share Shift Select
  3. Send link Select
  4. Send the invitation link using an app of your choice, such as KakaoTalk or text messages.
  5. Once the other person completes the connection, check the bottom Coworkers tab.
Check Coworker Shifts

Shifts from connected coworkers are available in the bottom Coworkers tab. Saved content is shown first, followed by a check for the latest data. When you open a coworker's screen or change the month, the latest shared shifts are checked again.

How the latest shifts are reflected may vary depending on the app version and feature settings.
Manage Coworkers

At the bottom, Coworkers use the coworker management feature to add coworkers or organize their display order, filters, and connection status.

5. Work Alarm

Set an alarm for each shift according to the different start times for each shift type.

Turn on the Work Alarm
  1. At the bottom, More Open it.
  2. Alarm Settings Select it.
  3. To the right of the shift for which you want to use an alarm switch Turn it on.
  4. When a permissions notice appears, allow the required alarm and notification permissions.
Change the alarm time for each shift

More → Alarm Settings Tap the desired shift card to change that shift’s alarm time. Changes are applied in Settings without a separate Save button.

Set the alarm sound, vibration, and alarm screen

More → All Settings in the upper right → Alarm to review settings for the Work Alarm, sound and vibration, and the alarm screen.

Is your alarm not ringing?View Work Alarm troubleshooting →

6. Home Widget

Check your shifts from your phone’s home screen without opening the app.

Add a ShiftMate widget to iPhone
  1. Press and hold the iPhone home screen, then enter edit mode.
  2. Add Widget and search for ShiftMate.
  3. Select the desired widget size and style.
  4. Place it on the home screen.
Add a ShiftMate widget to Android
  1. Press and hold the home screen, then Widgets open the menu.
  2. Find ShiftMate.
  3. Add the desired widget to the home screen.
The name and location of the widget addition screen may vary slightly depending on the Android manufacturer and version.
Set the content displayed in the widget

More → Widget Settings to set the shifts and related options displayed in the ShiftMate widget. To actually add the widget to the home screen, use the iPhone/Android home screen.

7. Notes

Bottom Notes Manage regular notes and checklist notes from the tab.

Create a note
  1. At the bottom, open the Notes tab.
  2. + Tap the button to open a note.
  3. Enter a title and content.
  4. At the bottom, tap Save.
Use checklist notes

If you want to review tasks you need to do item by item, change the note type to Checklist Note and add checklist items.

Find and sort notes

Use the filters and sorting features in the note list to quickly find the notes you need based on conditions such as regular notes or checklist notes, completion status, and date.

8. Attendance & Analysis

Manage records such as vacation, sick leave, training, business trips, late arrivals, and early departures separately from your Shift Schedule as Attendance.

Add an attendance record

Select a date in the shift calendar to open the date details screen, then + from the button Attendance select it to add a record.

To add or edit attendance types themselves, use More → All Settings in the upper right → Shifts, Time Off & Attendance → Attendance Settings.
Check Shift Analysis and Attendance & Leave

More → Shift Analysis to review shift patterns, and More → Attendance & Leave to review attendance records by period. In Attendance & Leave, you can set the date range to This month · Last month · Last 3 months · This year · Last year or Custom selection.

9. Account, Data & Settings

At the bottom, tap More and in the upper right tap All Settings to manage key settings and support menus.

Explore All Settings

More → All Settings in the upper right to manage the following areas.

  • Shifts, Time Off & Attendance — Shift types, attendance, and shift screen
  • Alarm — Work Alarm, sound, and vibration
  • Calendar — Region, week start day, and calendars to display
  • Display Settings — How shifts and schedules are displayed and their size
  • Theme — Display mode, colors, and font
  • Home Widget — Monthly and daily/weekly widget settings
Login and account

Login is used to access automatic backup and sharing features for shift data. Before changing phones, make sure you know the account information you are currently using.

Check data backup and restoration

After logging in, you can use backup and synchronization for supported data, as well as shift sharing. The data included in backup and restoration may vary by app version and data type, so check the account you are currently logged in to before changing devices or reinstalling the app. Log in with the same account on the new device.

Send help requests, inquiries, and feedback

All Settings → Help & support to access FAQ, Contact us, Feedback & improvements, and Rate ShiftMate.
