1. Getting started

You don’t need to read the guide from beginning to end. Learn the flow below and you can start using it right away.

Start using ShiftMate in 5 minutes
  1. the Shift tab at the bottom at the top Input to enter your first shift.
  2. More → Alarm Settings to turn on the Work Alarm for your shifts and check the time.
  3. ShiftMate on your phone’s home screen Home Widget Add it.
  4. If needed, More → Share Shift → Send link to send an invitation link to a coworker.
Recommended
At first, Input Shift → Work Alarm → Home Widget is all you need to set up.

2. Shift Schedule

At the bottom, Shift enter and review your shifts, such as D, E, N, and OFF, in the tab.

Input Shift

Shift → Input to edit your Shift Schedule.

  1. Open the Shift tab at the bottom.
  2. At the top of the screen, Input Tap it.
  3. Select the date to enter.
  4. Tap the desired shift button below, such as D, E, N, or OFF.
  5. When you’re finished entering shifts, tap Save in the top right.
Enter a monthly Shift Schedule quickly and consecutively

ShiftMate’s Input Shift screen does not let you select multiple dates at once; when you enter a shift for one date, the selection automatically moves to the next date This lets you quickly enter a month of shifts by tapping in order, such as D → E → N → OFF, while referring to your Shift Schedule.

  1. Shift → Input Open it.
  2. Select the date on which to start entering shifts.
  3. Tap the shift button for that date.
  4. When the selection moves to the next date, continue tapping the next shift.
  5. After entering all shifts, tap Save in the top right.
Tip
If you need to edit a date in the middle, select that date again on the calendar and continue entering it.
Edit or delete shifts

Shift → Input select the date to edit, tap a different shift, or select Delete and then tap Save.

Set up the shifts you use

More → Shift Settings to manage shift names, colors, shift times, and available shifts.

In All Settings, More → All Settings in the top right → Shifts, Time Off & Attendance → Shift Settings is another way to access it.
Check Shift Analysis

More → Shift Analysis to review entered shifts by period. Use it to examine the number of shifts by type and identify patterns.

3. Schedule

ShiftMate displays personal schedules from your device calendar alongside shifts and links to schedule-adding and editing features.

Add a personal schedule

At the bottom, Shift select the desired date in the tab, then + you can add a schedule from the button. Enter the details in ShiftMate’s schedule editing screen, and they will be saved to the selected device calendar.

To use personal schedules alongside your Shift Schedule, your device’s calendar access permission is required.
Set recurring schedules and schedule reminders

On the schedule editing screen, you can set recurrence settings such as daily, weekly, monthly, or yearly, along with reminders for the schedule.

Change how shifts and schedules are displayed

More → All Settings in the top right → Screen Settings to adjust the display style and size of shifts and schedules.

4. Coworkers · Share Shift

Connect with coworkers using an invitation link and view shared shifts together in the bottom Coworkers tab.

Send a Share Shift link to a coworker
  1. At the bottom, open More.
  2. Share Shift Select it.
  3. Send link Select it.
  4. Send the invitation link through the app you want, such as KakaoTalk or text messages.
  5. When the other person completes the connection, check it in the bottom Coworkers tab.
Check Coworker Shifts

Shifts from connected coworkers are available in the bottom Coworkers tab. Saved content is shown first, followed by the latest data check. When you open a coworker’s screen or change the month, the latest shared shifts are checked again.

How the latest shifts are reflected may vary depending on the app version and feature settings.
Manage coworkers

At the bottom, open the Coworkers screen to add coworkers or organize their display order, filters, and connection status using Coworker management.

5. Work Alarm

Set a Work Alarm for each shift according to its different start time.

Turn on the Work Alarm
  1. At the bottom, open More Open it.
  2. Alarm Settings Select it.
  3. On the right of the shift for which you want to use an alarm switch Turn it on.
  4. When a permissions notice appears, allow the required alarm and notification permissions.
Changing alarm times by shift

More → Alarm Settings Tap the desired shift card to change that shift's alarm time. Changes are applied to the settings without a separate Save button.

Setting the alarm sound, vibration, and alarm screen

More → All Settings in the top right → Alarm You can check settings related to the Work Alarm, sound and vibration, and the alarm screen.

Is your alarm not going off?View Work Alarm troubleshooting →

6. Home Widget

Check your shifts from your phone's home screen without opening the app.

Adding a ShiftMate widget to iPhone
  1. Press and hold the iPhone home screen, then enter edit mode.
  2. Add Widget Search for ShiftMate.
  3. Select the desired widget size and style.
  4. Place it on the home screen.
Adding a ShiftMate widget to Android
  1. Press and hold the home screen, then open the Widgets menu.
  2. Find ShiftMate.
  3. Add the desired widget to the home screen.
The name and location of the widget addition screen may vary slightly depending on the Android manufacturer and version.
Setting what appears in the widget

More → Widget Settings You can set the shifts and related options to display in the ShiftMate widget. To actually add the widget to the home screen, use the iPhone/Android home screen.

7. Notes

Bottom Notes Manage regular notes and checklist notes from the Notes tab.

Creating a note
  1. Open the bottom Notes tab.
  2. + Tap the button to open a note.
  3. Enter a title and content.
  4. At the bottom, tap Save.
Using checklist notes

If you want to review tasks by item, change the note type to Checklist note to add checklist items.

Finding and sorting notes

Use the filters and sorting features in the note list to quickly find the notes you need by conditions such as regular notes or checklist notes, completion status, and date.

8. Attendance & Analysis

Manage records such as annual leave, sick leave, training, business trips, late arrivals, and early departures separately from your Shift Schedule as Attendance.

Adding an attendance record

Select a date in the shift calendar to open the date details screen, then + from the button select Attendance to add a record.

To add or edit the attendance types themselves, use More → All Settings in the top right → Shifts, Time Off & Attendance → Attendance Settings.
Checking Shift Analysis and Attendance & Leave

More → Shift Analysis to review shift patterns, and More → Attendance & Leave to review attendance records by period. In Attendance & Leave, you can set the date range to this month, last month, the last 3 months, this year, or last year or select a custom range.

9. Account, Data & Settings

At the bottom, tap More and in the top right, tap All Settings to manage key settings and support menus.

Exploring All Settings

More → All Settings in the top right lets you manage the following areas.

  • Shifts, Time Off & Attendance — Shift types, Attendance, and the shift screen
  • Alarm — Work Alarm, sound, and vibration
  • Calendar — Region, start day of the week, and calendars to display
  • Display settings — How shifts and schedules are displayed and their size
  • Theme — Screen mode, colors, and fonts
  • Home Widget — Monthly and daily/weekly widget settings
Login and account

Login is used to access automatic backup and sharing features for shift data. Before changing phones, make sure you know the account information you currently use.

Checking data backup and restoration

After logging in, you can use backup and synchronization for supported data, as well as shift sharing. The data covered by backup and restoration may vary depending on the app version and data type, so check the account currently signed in before changing devices or reinstalling the app. Sign in with the same account on the new device.

Sending help requests, inquiries, and feedback

All Settings → Help & support provides access to FAQ, Contact us, Feedback & improvements, and Rate ShiftMate.
