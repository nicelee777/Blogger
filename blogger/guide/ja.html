1. 始める

説明書を最初からすべて読む必要はありません。以下の流れだけ覚えれば、すぐに使い始められます。

5分でShiftMateを始める
  1. 下部の勤務タブで上部の 入力をタップして、最初の勤務を入力します。
  2. その他 → アラーム設定で、使用する勤務の出勤アラームをオンにし、時刻を確認します。
  3. スマートフォンのホーム画面にShiftMateの ホームウィジェットを追加します。
  4. 必要に応じて その他 → 勤務共有 → リンクを送信から同僚に招待リンクを送信します。
おすすめ
最初は 勤務入力 → 出勤アラーム → ホームウィジェットだけ設定すれば十分です。

2. 勤務表

下部の 勤務 タブでD、E、N、OFFなどの自分の交替勤務を入力・確認します。

勤務を入力する

勤務 → 入力から勤務表を編集します。

  1. 下部の 勤務 タブを開きます。
  2. 画面上部の 入力をタップします。
  3. カレンダーで入力する日付を選択します。
  4. 下部のD、E、N、OFFなど、希望する勤務ボタンをタップします。
  5. 入力が終わったら右上の 保存をタップします。
1か月分の勤務表をすばやく連続入力する

ShiftMateの勤務入力画面は、複数の日付をまとめて選択する方式ではなく、 1つの日付に勤務を入力すると、選択位置が次の日付へ自動的に移動する方式です。 勤務表を見ながらD → E → N → OFFのように順番にタップすると、1か月分の勤務をすばやく入力できます。

  1. 勤務 → 入力を開きます。
  2. 入力を開始する日付を選択します。
  3. その日の勤務ボタンをタップします。
  4. 選択表示が次の日付へ移動したら、次の勤務を続けてタップします。
  5. すべて入力したら右上の 保存をタップします。
Tip
途中の日付を修正する場合は、カレンダーで該当の日付を再度選択して、そのまま入力を続けられます。
勤務を修正・削除する

勤務 → 入力で修正する日付を選択し、別の勤務をタップするか、 削除を選択した後、 保存します。

使用する勤務を設定する

その他 → 勤務設定で勤務名、色、勤務時間、使用する勤務を管理します。

すべての設定では その他 → 右上のすべての設定 → 勤務・勤怠／休暇 → 勤務設定からもアクセスできます。
勤務分析を確認する

その他 → 勤務分析で入力した勤務を期間別に確認できます。勤務の種類ごとの回数やパターンを確認するときに活用してください。

3. 予定

ShiftMateは、デバイスのカレンダーに登録された個人の予定を勤務と一緒に表示し、予定の追加・編集機能に連携します。

個人の予定を追加する

下部の 勤務 タブで希望の日付を選択した後、 + ボタンから予定を追加できます。ShiftMateの予定編集画面で内容を入力すると、選択したデバイスのカレンダーに保存されます。

個人の予定を勤務表と一緒に使用するには、デバイスの カレンダーへのアクセス権限が必要です。
繰り返し予定と予定のアラームを設定する

予定編集画面で、毎日・毎週・毎月・毎年などの 繰り返し設定と予定の アラームを設定できます。

勤務・予定の表示方法を変更する

その他 → 右上のすべての設定 → 画面設定で勤務と予定の表示方法やサイズを調整できます。

4. 同僚・勤務共有

招待リンクで同僚とつながり、下部の 同僚 タブで共有された勤務を一緒に確認します。

同僚に勤務共有リンクを送信する
  1. 下部の その他を開きます。
  2. 勤務共有を選択します。
  3. リンクを送信を選択します。
  4. カカオトークやSMSなど、希望するアプリで招待リンクを送信します。
  5. 相手が接続を完了すると、下部の 同僚 タブで確認できます。
同僚の勤務を確認する

接続された同僚の勤務は、下部の 同僚 タブで確認できます。保存された内容を先に表示した後、最新データを確認し、 同僚の画面を開いたり月を変更したりすると、最新の共有勤務を再度確認します。

最新の勤務を反映する方法は、アプリのバージョンや機能設定によって異なる場合があります。
同僚を管理する

下部の 同僚 画面で同僚管理機能を使用し、同僚の追加や表示順・フィルター・接続状態を整理できます。

5. 出勤アラーム

勤務の種類ごとに異なる出勤時刻に合わせて、勤務別のアラームを設定します。

出勤アラームをオンにする
  1. 下部の その他を開きます。
  2. アラーム設定を選択します。
  3. アラームを使用する勤務の右側にある スイッチをオンにします。
  4. 権限に関する案内が表示されたら、必要なアラーム・通知権限を許可します。
勤務別のアラーム時刻を変更する

その他 → アラーム設定で任意の勤務カードをタップすると、その勤務のアラーム時刻を変更できます。変更内容は保存ボタンを押さなくても設定に反映されます。

アラーム音・振動・アラーム画面を設定する

その他 → 右上のすべての設定 → アラームで、出勤アラーム、音量と振動、アラーム画面に関する設定を確認できます。

アラームが鳴りませんか？出勤アラームの問題解決を見る →

6. ホームウィジェット

スマートフォンのホーム画面で、アプリを開かずに勤務を確認できます。

iPhoneにShiftMateウィジェットを追加する
  1. iPhoneのホーム画面を長押しして、編集モードに入ります。
  2. ウィジェットを追加でShiftMateを検索します。
  3. 希望するウィジェットのサイズと形を選択します。
  4. ホーム画面に配置します。
AndroidにShiftMateウィジェットを追加する
  1. ホーム画面を長押しして ウィジェット メニューを開きます。
  2. ShiftMateを探します。
  3. 希望するウィジェットをホーム画面に追加します。
Androidのメーカーやバージョンによって、ウィジェット追加画面の名称や位置が多少異なる場合があります。
ウィジェットの表示内容を設定する

その他 → ウィジェット設定で、ShiftMateウィジェットに表示する勤務や関連オプションを設定できます。ホーム画面にウィジェットを実際に追加する操作は、iPhone／Androidのホーム画面で行います。

7. メモ

下部の メモ タブで、通常のメモとチェックメモを管理します。

メモを作成する
  1. 下部の メモ タブを開きます。
  2. + ボタンを押してメモを開きます。
  3. タイトルと内容を入力します。
  4. 下部の 保存をタップします。
チェックメモを使用する

やるべきことを項目ごとに確認したい場合は、メモの種類を チェックメモに変更して、チェック項目を追加できます。

メモを探す・並べ替える

メモ一覧のフィルターと並べ替え機能を使うと、通常のメモ・チェックメモ、完了状況、日付などの条件で必要なメモをすばやく探せます。

8. 勤怠・分析

年次休暇、病気休暇、研修、出張、遅刻、早退など、勤務表とは別に管理する記録を勤怠として管理します。

勤怠記録を追加する

勤務カレンダーで日付を選択して日付詳細画面を開き、 + ボタンから 勤怠を選択して記録を追加できます。

勤怠の種類自体を追加または編集するには、 その他 → 右上のすべての設定 → 勤務・勤怠／休暇 → 勤怠設定を利用してください。
勤務分析・勤怠状況を確認する

その他 → 勤務分析で勤務パターンを、 その他 → 勤怠状況で勤怠記録を期間別に確認できます。勤怠状況では、 今月・先月・過去3か月・今年・昨年 または 直接選択で照会期間を設定できます。

9. アカウント・データ・設定

下部の その他と右上の すべての設定で、主な設定とサポートメニューを管理します。

すべての設定を見る

その他 → 右上のすべての設定で、次の項目を管理できます。

  • 勤務・勤怠／休暇 — 勤務の種類、勤怠、勤務画面
  • アラーム — 出勤アラーム、音、振動
  • カレンダー — 地域、週の開始曜日、表示するカレンダー
  • 画面設定 — 勤務・予定の表示方法とサイズ
  • テーマ — 画面モード、色、フォント
  • ホームウィジェット — 月間・日間／週間ウィジェット設定
ログインとアカウント

ログインは、勤務データの自動バックアップや共有機能を利用するために使用します。スマートフォンを変更する前に、現在使用中のアカウント情報を確認しておいてください。

データのバックアップ・復元を確認する

ログインすると、対応するデータのバックアップ・同期や勤務共有機能を利用できます。バックアップ・復元の対象はアプリのバージョンやデータの種類によって異なる場合があるため、端末を変更したりアプリを再インストールしたりする前に、現在ログインしているアカウントを確認してください。新しい端末でも同じアカウントでログインしてください。

ヘルプ・お問い合わせ・ご意見を送る

すべての設定 → ヘルプとサポートで FAQ、お問い合わせ、ご意見・改善のご提案、ShiftMateを評価を利用できます。

10. 問題が発生した場合

通常の使用方法はこのガイドで確認し、エラーや予期しない動作については FAQで確認してください。

  • 出勤アラームが鳴りません。
  • ホームウィジェットが更新されません。
  • 同僚の勤務が最新の状態で表示されません。
  • 共有リンクが開きません。
  • ログイン・認証またはデータ復元に問題があります。
  • 予定や祝日の表示がおかしいです。
